# VK AI-бот

Бот для личных сообщений и бесед ВКонтакте. Получает сообщения от имени сообщества, передаёт их выбранной языковой модели, сохраняет историю в SQLite и отправляет ответ обратно в VK.

## Возможности

- Отвечает на личные сообщения сообщества.
- В беседах отвечает реплаем, если в сообщении как отдельное слово встречается «Пенёк», «Пенек», «Пенёчек» или «Пенечек»; слово «Бот» и значение `BOT_NAME` для обращения не распознаются. Также отвечает на настоящее VK-упоминание (`@club<ID>`) и на ответ через функцию VK «Ответить» на сообщение сообщества. Команды `/` и `!` продолжают работать. Остальные текстовые сообщения сохраняются для пересказа, но сами по себе не вызывают ответ.
- Поддерживает команды с префиксами `/` и `!`.
- `Пенек пересказ` и `/summary` выполняют одно и то же: сразу показывают пересказ за последние 2 часа. Кнопки под пересказом переключают период на 2 или 6 часов, редактируя исходное сообщение.
- Генерирует картинки по команде `Пенёк, нарисуй <описание>` и преобразует приложенное изображение по команде `Пенёк, преобрази <описание>` (можно ответить командой на сообщение с фотографией).
- В групповых беседах администраторы могут включить приветствия новых участников и анкету-знакомство; бот запоминает вступления и выходы, чтобы отличать новых участников от возвращающихся.
- Сохраняет историю отдельно по пользователям и беседам; в группах ИИ получает только общий контекст беседы. История удаляется не позднее 24 часов.
- Поддерживает режимы беседы `active`, `normal` и `quiet`, игровые сессии, перевод, подключаемый поиск и голосовые сообщения.
- Хранит историю сообщений в SQLite с помощью Prisma; контекст ограничен временем жизни и лимитом токенов.
- Обрабатывает запросы каждого пользователя последовательно.
- Во время генерации ответа в беседе показывает статус «печатает» через токен сообщества.
- Поддерживает OpenAI и OpenCode как провайдеры текстового ИИ, с переключением через конфигурацию или команду администратора.
- Периодически удаляет сообщения, срок хранения которых истёк.

## Требования

- Node.js 22 или новее и npm.
- Токен доступа сообщества VK с разрешением на сообщения.
- ID сообщества VK.
- API-ключ выбранного AI-провайдера.

В настройках сообщества VK включите сообщения и Long Poll, чтобы бот получал новые события.
Для переключения периода пересказа также включите событие `message_event` в настройках Long Poll сообщества, иначе VK не передаст боту нажатия callback-кнопок.

## Установка и запуск

Скопируйте пример конфигурации:

```bash
cp .env.example .env
```

Заполните `.env` (описание переменных — ниже), затем выполните:

```bash
npm ci
npx prisma generate
npx prisma migrate deploy
npm run dev
```

Для запуска собранной версии:

```bash
npm run build
npm start
```

## Настройка

### VK

```env
VK_TOKEN=токен_сообщества
VK_GROUP_ID=числовой_ID_сообщества
```

- `VK_TOKEN` — токен сообщества, которым бот получает и отправляет сообщения.
- `VK_GROUP_ID` — числовой ID сообщества без префикса `club`.

### Текстовый ИИ

```env
AI_PROVIDER=opencode
OPENCODE_API_KEY=ключ_OpenCode_Console
OPENCODE_MODEL=deepseek-v4.1-flash
OPENCODE_BASE_URL=https://opencode.ai/inference/go/openai/v1
OPENAI_API_KEY=ключ_OpenAI
OPENAI_MODEL=gpt-4.1-mini
```

`AI_PROVIDER` принимает `opencode` или `openai`. Укажите API-ключ выбранного провайдера; ключи остаются в `.env`, не в базе данных. Провайдера также можно поменять командой `/provider` администратора. Создайте ключ OpenCode в [OpenCode Console](https://opencode.ai/console); для OpenAI используйте [API dashboard](https://platform.openai.com/api-keys).

OpenAI SDK автоматически повторяет временные ошибки с ограниченным числом повторов; `AI_MAX_RETRIES`, `MAX_HISTORY_MESSAGES` и `MAX_HISTORY_TOKENS` задают соответственно лимит повторов и контекста.

### Генерация и редактирование изображений

```env
IMAGE_PROVIDER=openai
OPENAI_API_KEY=ключ_OpenAI
OPENAI_IMAGE_MODEL=gpt-image-1
CLOUDFLARE_ACCOUNT_ID=ID_аккаунта_Cloudflare
CLOUDFLARE_API_TOKEN=токен_Cloudflare
CLOUDFLARE_IMAGE_MODEL=@cf/black-forest-labs/flux-2-dev
```

По умолчанию используется OpenAI Images API с моделью `gpt-image-1` и качеством `high` для генерации и редактирования. Для альтернативы установите `IMAGE_PROVIDER=cloudflare`; тогда нужны Cloudflare Account ID и API-токен с разрешением Workers AI. Cloudflare предоставляет 10 000 Neurons в день бесплатно, а дальнейшее использование на Workers Paid оплачивается по действующему тарифу.

Генерация изображений ограничена администраторами по умолчанию. Настройте `VK_ADMIN_IDS` как список числовых VK ID через запятую. Администратор может выдать доступ в беседе через `/imageaccess all`.

### Голос и веб-поиск

```env
VOICE_ENABLED=false
OPENAI_TRANSCRIPTION_MODEL=gpt-transcribe
OPENAI_TTS_MODEL=gpt-4o-mini-tts
WEB_SEARCH_PROVIDER=none
BRAVE_SEARCH_API_KEY=
```

Для голосового ввода/ответов задайте `VOICE_ENABLED=true`, настройте `OPENAI_API_KEY`, затем пользователь включает функцию командой `/voice on` и может выбрать голос через `/voice <voice>`. Команда `/voice off` отключает голосовой ответ. Веб-поиск подключается через Brave Search API; пока `WEB_SEARCH_PROVIDER=none`, команда поиска выключена.

### Пользовательские настройки и беседы

- По умолчанию бот отвечает коротко и прямо, без лишних любезностей. `/personality` открывает меню пяти персонажей с кнопками; `/personality <id>` выбирает персонажа только для личных сообщений. Доступны `/personality info`, `list`, `default`, `settings`, `settings humor=70 sarcasm=30` и `reset`. Настройки хранятся отдельно для пользователя и каждого персонажа.
- `/chatpersonality` показывает меню персонажа беседы; `/chatpersonality <id>` или `/chatpersonality default` меняет его с правами администратора беседы/бота. `/chatpersonality allow|deny` разрешает или запрещает смену всем участникам; по умолчанию разрешение выключено.
- Администратор бота может управлять профилями командами `/personality add id|имя|описание|пример|инструкция`, `/personality edit id|name|значение`, `/personality prompt id|инструкция`, `defaults id|humor=70|influence.sarcasm=80`, `enable`, `disable`, `availability`, `exclusive` и `access`; `default <id>` назначает профиль по умолчанию, `rollback id|версия` восстанавливает снимок, `stats [id]` показывает успешные ответы. Системные инструкции не показываются публичными командами.
- `/system` показывает личную инструкцию, `/system <текст>` задаёт её, `/system clear` удаляет.
- Администратор может задать общую инструкцию бота командами `/system global <текст>` и `/system global clear`.
- В групповой беседе администратор задаёт режим командой `/mode active|normal|quiet`. Обычный режим отвечает на упоминания, команды и ответы боту; активный дополнительно реагирует на вопросы и явные просьбы; тихий отвечает только на команды администратора.
- Команды `/welcome on|off` и `/welcome set <текст>` управляют приветствием в текущей беседе (подстановка `{name}` — имя участника). По умолчанию приветствия выключены. `/questionnaire on|off` включает или выключает анкету; `/questionnaire set <вопрос 1> | <вопрос 2>` задаёт от 1 до 8 вопросов. Анкеты по умолчанию выключены, начальные вопросы предназначены для знакомства. Администратор беседы, администратор бота или создатель могут управлять этими настройками.
- При первом замеченном вступлении бот предлагает заполнить анкету, если она включена. Участники, уже находящиеся в беседе, также могут начать её через `/profile` или `/profile create`; `/profile edit` обновляет анкету, `/profile show` показывает её, `/profile cancel` отменяет заполнение. Администраторы бота могут получить список анкет текущей беседы командой `/profiles [страница]`, просмотреть `/profile get <VK ID>`, изменить ответ `/profile edit <VK ID> <номер ответа> <текст>` или удалить `/profile delete <VK ID>`. Результаты администраторских команд отправляются в личные сообщения администратора.
- TTL ограничен 24 часами; `/reset` очищает историю пользователя в текущем разговоре, `/forget` — личную историю пользователя во всех беседах. Смена персонажа не очищает историю.
- `/games quiz|riddle|word|truth|who|association|adventure|detective|story` запускает отдельную игровую сессию беседы. Загадки генерирует текущий ИИ-провайдер; сложность можно менять командами `/games harder` и `/games easier`, проверить — `/games difficulty`. `/games top` показывает таблицу очков.
- Административные команды проверяют VK ID: `/admin`, `/users`, `/logs`, `/provider`, `/maintenance`, `/broadcast`.
- Роль «Создатель» выше роли «Администратор» и закреплена за Mark Puchkov (VK ID `388581097`). Создатель автоматически имеет права администратора; только он может назначать и снимать администраторов. Остальных администраторов задают через `VK_ADMIN_IDS` или команду `/admin add|remove`.

### Прочие параметры

```env
DATABASE_URL=file:./dev.db
PORT=3000
LOG_LEVEL=info
BOT_NAME=awesome_bot
CONTEXT_TTL_HOURS=24
MAX_HISTORY_TOKENS=4000
MAX_HISTORY_MESSAGES=30
MAX_INPUT_CHARS=12000
MAX_REQUESTS_PER_MINUTE=10
```

- `DATABASE_URL` — адрес базы данных; по умолчанию используется локальная SQLite.
- `PORT` — порт приложения.
- `LOG_LEVEL` — уровень логирования.
- `BOT_NAME` — имя экземпляра бота для журналов запуска; для обращения в беседе используются только «Пенёк/Пенек» и «Пенёчек/Пенечек».
- `CONTEXT_TTL_HOURS` — сколько часов хранить сообщения в контексте.
- `MAX_HISTORY_TOKENS` — приблизительный лимит истории, передаваемой модели.

## Команды

Команды можно отправлять с `/` или `!`; пересказ в беседе вызывается фразой `Пенек пересказ`:

| Команда                                 | Действие                                        |
| --------------------------------------- | ----------------------------------------------- |
| `/help` или `!help`                     | Показать список команд                          |
| `/ping` или `!ping`                     | Проверить отклик бота                           |
| `Пенек пересказ`                        | Пересказать беседу за последние 2 часа          |
| `Пенёк, нарисуй <описание>`             | Создать изображение по описанию                 |
| `Пенёк, преобрази <описание>`           | Изменить прикреплённое фото или фото из ответа  |
| `/reset` или `!reset`                   | Удалить историю пользователя в текущем диалоге  |
| `/forget` или `!forget`                 | Удалить всю историю пользователя                |
| `/system <текст>` или `!system <текст>` | Добавить системное сообщение в контекст         |
| `/document <вопрос>`                    | Проанализировать прикреплённый PDF или документ |
| `/welcome on\|off`                      | Включить или выключить приветствие в беседе     |
| `/welcome set <текст>`                  | Настроить текст приветствия; доступно админам   |
| `/questionnaire on\|off`                | Включить или выключить анкету; доступно админам |
| `/questionnaire set <вопросы>`          | Настроить вопросы через `\|`; доступно админам  |
| `/profile [create\|edit\|show\|cancel]` | Заполнить, изменить или показать свою анкету    |
| `/profiles [страница]`                  | Список анкет текущей беседы (админы бота)       |
| `/profile get <VK ID>`                  | Посмотреть анкету (админы бота, в личку)        |
| `/profile edit <ID> <номер> <текст>`    | Изменить ответ в анкете (админы бота, в личку)  |
| `/profile delete <VK ID>`               | Удалить анкету (админы бота, в личку)           |
| `/summary`                              | Пересказать беседу за последние 2 часа          |
| `/summary 2` или `/summary 6`           | Сразу пересказать беседу за выбранный период    |

## Docker

Для запуска через Compose подготовьте `.env`, затем выполните:

```bash
docker compose up --build -d
```

## Размещение в облаке

Приложение использует одну SQLite-базу, указанную в `DATABASE_URL`. Для размещения на VM или контейнерной платформе подключите постоянный диск, например задав `DATABASE_URL=file:/data/bot.db` и смонтировав диск в `/data`: без постоянного хранилища история будет потеряна при пересоздании контейнера. Используйте один экземпляр бота, чтобы все процессы работали с одной базой.

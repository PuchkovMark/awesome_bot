## Упорядоченные шаги

### 1. Распознать создание напоминания в подтверждённом ответе

- **Цель.** Передать собственную просьбу автора «напомни мне» существующему обработчику до выбора обычного ответа модели.
- **Изменение.** В `src/core/reminders/commands.ts` уточнить `incomingReminderCommand`. Для подтверждённого ответа другому участнику (`replyAddress === 'other'`) разрешить в группе только команду вида `create` от подтверждённого человека (`isBot === false`). Адаптер должен передать `isMentioned === true` и `soleBotMention === true`. Отсутствие второго признака не подтверждает адресацию. Неизвестный адресат ответа исключает команду. Для разбора использовать `parseReminderCommand` с нормализованным текстом автора. Распознавание и исполнение в `src/app/reminders.ts` уже используют `incomingReminderCommand`, а получателя обработчик определяет по `event.userId`. [Распознавание](../../src/core/reminders/commands.ts) · [Обработчик приложения](../../src/app/reminders.ts)
- **Тесты.** В новом файле `tests/reminder-commands.unit.test.ts` проверить разрешённый `create`, неизвестного адресата, отсутствующий или ложный признак единственного упоминания и команду «Мои напоминания» в таком же ответе. В `tests/helpers/application-reminders-fixture.ts` расширить существующий `send` необязательной исходной репликой для `reply_message`. Обе реплики должны читаться через подмену `messages.getByConversationMessageId`. В `tests/application-reminders.test.ts` отправить нейтральное сообщение Саши (42), затем ответ Иры (41) в той же беседе с выбранным упоминанием Пенька. Проверить задание в `vk:41`, подтверждение только Ире и ноль вызовов модели.

  ```sh
  npm run build
  npm test -- tests/reminder-commands.unit.test.ts tests/application-reminders.test.ts tests/vk-inbound-normalization.test.ts
  ```

- **Готово, когда** сборка и тесты проходят, а пример задачи через штатный вход VK создаёт одно личное задание и даёт Ире подтверждение.

### 2. Проверить доставку, повтор события и неоднозначную адресацию

- **Цель.** Подтвердить, что оба разрешённых способа обращения дают автору одну доставку, а неясная адресация оставляет бота в молчании.
- **Доставка и повторы.** В `tests/application-reminders.test.ts` проверить просьбу с выбранным упоминанием в ответе Саше и отдельным сообщением. В каждом сценарии повторить ту же реплику через `repeat` с исходным номером VK. С помощью `pending`, `at` и `sends` проверить одну запись с тем же ID, одно подтверждение и одну доставку в личку 41 через 20 минут от времени просьбы. Для ответа взять более раннюю реплику Саши с другим текстом. В беседе и в личке 42 отправок нет. Проверить ноль вызовов модели, служебное назначение записи просьбы в журнале и отсутствие её в `storage.contextMessages.search` по отличительному слову поручения. [Сквозные тесты](../../tests/application-reminders.test.ts) · [Хранение повторов](../../src/storage/reminder-store.ts)
- **Тишина и закрытая личка.** Через тот же стенд проверить три ответа Саше. В первом имя «Пенёк» набрано текстом, во втором рядом с ботом выбран ещё один адресат. В третьем выбран только бот, но VK при проверке ответа не подтверждает исходное сообщение Саши. Для этого дать тесту возможность скрыть номер сообщения из результата чтения через существующий набор `hidden` в подмене VK. Дождаться обработки событий по их номерам в журнале и проверить отсутствие заданий, исходящих сообщений и вызовов модели. Отдельно закрыть личку Иры через `privateAccess` и отправить правильно адресованную просьбу. Ожидается только действующая подсказка в группе с предложением разрешить сообщения, без текста поручения и создания задания. [Подмена VK и часы](../../tests/helpers/application-reminders-fixture.ts)

  ```sh
  npm run build
  npm test -- tests/application-reminders.test.ts tests/storage-reminders.test.ts tests/message-router-policy.test.ts tests/router-admission.test.ts
  ```

- **Готово, когда** сборка и тесты проходят. По сохранённому заданию и адресатам отправок видны автор просьбы, срок и результат каждого повтора. Для трёх случаев с неясной адресацией подтверждена тишина.

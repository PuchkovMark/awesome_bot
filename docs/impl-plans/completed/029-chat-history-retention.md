## Согласованные начальные параметры

| Параметр | Значение |
| --- | --- |
| Срок сообщений | `MESSAGE_RETENTION_DAYS`, заданный оператором для всей установки |
| Срок трассировки | Действующий отдельный срок F2.6, по умолчанию 7 суток и короче срока сообщений |
| Срок одноразового подтверждения | 5 минут с момента запроса. В точный момент истечения подтверждение недействительно |
| Период обслуживания | Первый проход при запуске после получения владения. Затем проверка раз в 60 секунд и при подтверждении очистки |
| Размер порции | До 100 сообщений или 100 отдельно просроченных трассировок в одной транзакции. При остатке очередь получает возможность обработать сообщения, затем обслуживание берёт следующую порцию в том же цикле |

В беседе предлагаются `/очистить-историю` и `/подтвердить-очистку <код>`. Владелец в личке начинает с `/очистить-историю vk:<peer_id>@<поколение>` и подтверждает там же. Код обозначает конкретный запрос. Харнес проверяет полномочия независимо от знания кода.

При истечении в лимитере VK первая доставленная часть сохранилась, вторая не отправилась. Проверки используют временные SQLite и подмены VK и провайдера.

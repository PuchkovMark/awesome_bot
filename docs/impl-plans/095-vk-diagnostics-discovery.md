## Упорядоченные шаги

### 1. Добавить тему «Управление» в групповую справку

- **Цель.** Администратор бота и владелец находят в `/помощь` тему своей беседы и получают две готовые к копированию строки с указанием, куда их отправить.
- **Изменения.** В `src/app/service.ts` передать в `commandHelp` из группового запроса `context.scope`. В `src/app/command-help.ts` определять доступность групповых тем по наличию этой области. При обычном запросе в личке и при показе служебной справки владельца групповая область отсутствует. В список тем администратора или владельца включённой беседы добавить `/помощь управление`. Оба имени справки, `/помощь` и `/команды`, используют ту же ветку. [Вызовы справки](../../src/app/service.ts) · [Формирование тем](../../src/app/command-help.ts)
- **Ответ.** Показать `/продлить-паузу 5` отдельной строкой и указать, что команда в беседе прибавляет пять минут к действующей паузе. Следующей инструкцией предложить отправить в личку сообщества строку `почему ты так ответил` с фактическими `chatId@generation`. Формат совпадает с уже показанным в `/настройки`. Для формирования текста достаточно переданной области. Перед отправкой справки действуют текущие проверки роли и режима. [Формат подключения](../../src/core/chat-control/service.ts) · [Разбор команд](../../src/core/chat-control/commands.ts)
- **Тесты.** В `tests/application-command-help.test.ts` открыть тему из общего списка, проверить выдачу администратору и владельцу, совпадение двух имён справки и подстановку реального поколения. Обновить точное ожидание списка тем при опечатке в молчаливом режиме. Обычный участник при прямом запросе темы получит только доступную ему справку, если его режим разрешает ответ. В личной справке владельца проверить существующие служебные команды. В активной беседе с уже начатой паузой убедиться, что открытие темы сохраняет её срок, а отправка скопированной команды продления добавляет пять минут к прежнему концу. [Проверки справки](../../tests/application-command-help.test.ts) · [Проверки паузы](../../tests/chat-control-service.test.ts)

  ```sh
  npm run build
  npm test -- tests/application-command-help.test.ts tests/chat-control-service.test.ts
  ```

- **Готово, когда** сборка и тесты проходят. Обе команды можно скопировать по строке, роль определяет видимость темы, а адрес беседы берётся из самого запроса справки.

### 2. Проверить путь от справки двух бесед до личных сводок

- **Цель.** Подтвердить на штатном входе VK, какую сводку получит человек, если скопирует подсказку целиком. Для проверки использовать `setupControlApplication` из `tests/application-chat-control.test.ts` с подменами VK и модели. [Стенд и проверки личной диагностики](../../tests/application-chat-control.test.ts)
- **Положительный сценарий.** В тестовой БД открыть беседы A и B с разными ID и поколениями. Дождаться доставки обычного ответа в каждой. Использовать различимые поводы, например упоминание в A и обращение по имени в B. В обеих выдать одному человеку права администратора. Последовательно пройти `/помощь` → `/помощь управление`, взять команду прямо из опубликованного сообщения и отправить её тому же боту из лички администратора. Сверить получателя и повод в каждой сводке. Владелец должен пройти тот же путь. Для пользователя с правом доступа и без доставленного ответа проверить штатное сообщение об отсутствии сводки. [Выбор доставленного ответа](../../src/core/response-tracing/diagnostics.ts)
- **Границы доступа.** Проверить опубликованные в группах инструкции и доставленные в личку сводки отдельно. Участник может видеть групповое сообщение администратора. Копирование строки участником не даёт ему сводку. После отзыва прав в B снова отправить обе строки из лички администратора. Ему должна прийти только сводка A. Для проверки старой команды сменить поколение B в тестовой БД, доставить в неё новый обычный ответ и запросить объяснение от владельца по старой и новой строкам. Дождаться обработки запросов, затем сравнить фактические отправки. Сводка нового поколения должна прийти только по его строке. Существующая проверка отзыва прав во время отправки также входит в прогон. [Личный обработчик](../../src/app/chat-control.ts) · [Правила доступа](../specs/security.md#доступ-к-трассировкам-f26)

  ```sh
  npm run build
  npm test -- tests/application-chat-control.test.ts tests/application-command-help.test.ts tests/storage-traces.test.ts
  ```

- **Готово, когда** сборка и тесты проходят. Для A и B проверены разные адреса команд, поводы ответа и фактические получатели. В публичной выдаче справки есть инструкция, а все диагностические сводки отправлены только в личку с действующими правами.

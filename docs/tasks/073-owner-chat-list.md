- Дата завершения: —
- Связанные документы: [F10.2 в дорожной карте](../roadmap.md#веха-10-личный-кабинет) · [Вход владельца](072-owner-web-sign-in.md)

## Проблема или цель

Владелец должен видеть, какие чаты подключены и в каких беседах требуется его решение после разрыва связи.

## Ожидаемое поведение

Кабинет показывает личные диалоги и групповые беседы VK. Для каждого чата видны платформа, тип, применимый режим и состояние подключения. Для приостановленной беседы видна причина.

## Критерии приёмки

- Подготовить личный диалог и несколько групп VK с разными режимами и состояниями. Сопоставить каждую строку списка с соответствующим чатом и настройками.
- При двух одновременно приостановленных беседах владелец находит обе и видит причину каждой. Список совпадает с результатом штатного просмотра F3.7. После решения по одной беседе её состояние меняется при следующем просмотре.
- Проверить случай без приостановленных бесед и отсутствие доступа к межчатовому списку владельца из сессии другого пользователя.

## Что явно не входит

Просмотр диагностических сведений отдельной беседы, изменение настроек и подключение Telegram.

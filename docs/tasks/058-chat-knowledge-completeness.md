## Проблема или цель

Когда поиск по истории ничего не вернул, участнику важно понять, удалось ли проверить журнал. Задача проверяет, как бот объясняет результат уже действующего инструмента.

## Ожидаемое поведение и критерии приёмки

Один и тот же вопрос о встрече задаётся в трёх синтетических беседах с разным исходом поиска.

| Исход поиска | Что получает участник |
| --- | --- |
| Найдена реплика с местом встречи | Прямой ответ с подтверждённым местом без выдуманной оговорки. |
| Поиск завершился успешно, совпадений нет | Бот сообщает, что в доступной переписке совпадений не нашёл. Утверждение «встречу не обсуждали» считается ошибкой. |
| Поиск завершился технической ошибкой | Бот сообщает, что сейчас проверить историю не удалось. Сообщение об отсутствии совпадений считается ошибкой. |

Для каждого случая сверяются результат инструмента, полученный моделью, и смысл опубликованного ответа. Примеры допускают разные формулировки.

## Границы задачи

Работа ограничена оценкой существующего поиска. К расширению формата выдачи и обработке границ хранения можно вернуться, если обнаружится конкретный вопрос, для которого боту не хватает данных инструмента. Сводки и память 057 находятся за пределами этих проверок.

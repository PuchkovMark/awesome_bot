# Задача 077 — Токен-бюджеты выбранной беседы в кабинете

- Связанные документы: [F10.3 в дорожной карте](../roadmap.md#веха-10-личный-кабинет) · [Карточка беседы](074-owner-chat-diagnostics.md)

## Проблема или цель

У харнеса есть операция F4.6 для изменения лимитов. Владельцу нужно видеть и менять значения для конкретной беседы через кабинет.

## Ожидаемое поведение

Карточка показывает общий токен-бюджет чата и бюджет самостоятельных реплик группы. Владелец меняет пределы и возвращает штатные значения по правилам F4.6.

## Критерии приёмки

- На группе с известным расходом изменить общий предел и предел инициативы. После повторного открытия и перезапуска значения совпадают с F4.6, ранее учтённый расход сохраняется.
- Подать прямое обращение и допустимый повод для самостоятельной реплики при достаточном общем остатке и исчерпанном остатке инициативы. Проверить применение обоих ограничений к следующим обращениям по правилам F4.6.
- Вернуть исходные правила расчёта. В личке применим только общий бюджет. Устаревшее поколение и сессия без прав владельца не меняют значения. Пределы соседнего чата сохраняются.

## Что явно не входит

Изменение формул, категорий расхода или правил бронирования токенов, исторический отчёт F10.4.

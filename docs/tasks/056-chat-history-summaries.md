## Проблема или цель

Пересказ насыщенного дня должен учитывать события за пределами первой страницы поиска и укладываться в бюджет модели.

## Ожидаемое поведение

Фоновая обработка сохраняет краткие итоги фрагментов переписки. Ночью по времени беседы из них составляется сводка дня. В контексте доступны итоги последних двух-трёх дней и скользящая сводка.

## Критерии приёмки

- Распределить решения, обещания и даты по началу, середине и концу дня из 10 000 сообщений. Проверить их в пересказе, ограниченность каждого запроса и исключение стикеров и односложных реакций из сжатия.
- При готовых фрагментах дневная сводка строится по кратким текстам. Если их нет, участник сразу получает «собираю, минутку», затем пересказ по частям с учётом квот. Проверить границу дня и неполный последний фрагмент.
- После перезапуска между обработанными фрагментами ни один исходный диапазон не теряется и не дублируется в результате. Проверить скользящую сводку при смене дня.
- Удалить один из источников. Зависимые сводки сразу скрываются, допустимая пересборка использует только доступные сообщения той же беседы.

## Что явно не входит

Извлечение долговременных фактов и редактирование паспорта.

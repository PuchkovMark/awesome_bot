## Проблема или цель

Решения и устойчивые договорённости должны оставаться доступными после выхода обсуждения из недавней истории.

## Ожидаемое поведение

Участник задаёт вопрос о давней договорённости своими словами, без даты и точной цитаты. В пределах срока хранения бот отвечает по доступным источникам текущей беседы, учитывает явные исправления и укладывается в бюджет запроса. Способ хранения фактов остаётся выбором реализации. Для персональных сведений действуют правила видимости профиля.

## Критерии приёмки

- В одной беседе участники сначала выбирают библиотеку для обмена книгами, а спустя несколько дней отвечают на исходную реплику «Переносим в клуб». Обе реплики выходят из окна сообщений и недельного обзора. После перезапуска на вопрос «Куда теперь приносить книги?» бот называет клуб как единственное актуальное место. По фактическому вводу модели можно проверить, что ей было доступно исправление.
- В другой беседе участники выбирают другое место. Каждый ответ опирается только на источники своего подключения. При скрытии персонального поля группа не получает закрытое значение, даже если сохранились исходная реплика и сводка. Скрытие поля во время подготовки ответа останавливает публикацию зависимого текста.
- Дважды обработать один и тот же источник с единственным предложением места. В обоих прогонах остаётся одно предложение с тем же первичным источником. Повторная обработка не превращает его в подтверждённую договорённость. При двух противоречащих сообщениях без развязки бот сообщает о неопределённости.
- После удаления одного источника смешанная сводка и подготовленный по ней ответ сразу исключаются из выдачи. После перезапуска для нового ответа пригодны оставшиеся доступные источники. Если их недостаточно, бот сообщает об этом.

## Что явно не входит

Автообновление личных профилей из 048, ручная правка паспорта и сводки дня.

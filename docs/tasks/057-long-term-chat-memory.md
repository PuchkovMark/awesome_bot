## Проблема или цель

Решения и устойчивые договорённости должны оставаться доступными после выхода обсуждения из недавней истории.

## Ожидаемое поведение

Бот извлекает подтверждаемые факты о беседе, связывает их с источниками и использует актуальные сведения в пределах бюджета. Для персональных сведений действуют правила видимости профиля.

## Критерии приёмки

- Зафиксировать договорённость о месте встречи. После перезапуска и выхода исходных сообщений из недавнего окна получить верный ответ с опорой на память текущей беседы.
- Добавить в другой беседе противоречащую договорённость. Проверить изоляцию и отсутствие закрытых личных фактов в общем ответе.
- Повторно обработать один источник, затем явно исправить договорённость. Повтор не создаёт второго факта, прежний вариант не выдаётся как актуальный.
- Проверить предположение без подтверждения и удаление источника сохранённого факта. Предположение не становится установленной договорённостью. Применяются правила удаления производных данных, включая скрытие записи со смешанными источниками.

## Что явно не входит

Автообновление личных профилей из 048, ручная правка паспорта и сводки дня.

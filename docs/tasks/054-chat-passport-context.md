## Проблема или цель

Участник может прочитать паспорт по команде 051. Для обычного ответа боту также нужны правила и значения местных выражений.

## Ожидаемое поведение

При подготовке ответа бот получает доступные разделы паспорта текущей беседы в пределах бюджета контекста. Содержимое паспорта служит справкой и не даёт полномочий.

## Критерии приёмки

- Задать слову «маяк» разные значения в двух беседах. При одинаковом вопросе в каждом запросе модели присутствует только местное определение.
- Изменить правило, затем очистить раздел. Следующие запросы отражают актуальную редакцию и не содержат удалённый текст.
- Заполнить разделы до предела. Итоговый запрос укладывается в бюджет, текущее сообщение сохраняется. Пустой паспорт допускает обычный ответ.
- Поместить в глоссарий указание выдать права. Проверить сохранение границы системных инструкций и отсутствие привилегированного действия.

## Что явно не входит

Редактор паспорта выполнен в 051. Автоматическое извлечение сведений из переписки относится к памяти.

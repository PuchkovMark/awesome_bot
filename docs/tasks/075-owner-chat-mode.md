# Задача 075 — Включение бота и выбор режима из карточки беседы

- Номер: 075
- Название: Включение бота и выбор режима из карточки беседы
- Статус: черновик
- Дата: 2026-11-24
- Дата завершения: —
- Связанные документы: [F10.3 в дорожной карте](../roadmap.md#веха-10-личный-кабинет) · [Карточка беседы](074-owner-chat-diagnostics.md)

## Проблема или цель

Владельцу нужен доступ к штатному управлению выбранной беседой через веб-кабинет.

## Ожидаемое поведение

Владелец видит включение и режим группы, меняет режим, выключает и снова включает бота. Каждое действие относится к указанному действующему поколению чата и подчиняется F4.2.

## Критерии приёмки

- Изменить режим группы через карточку, сверить его штатной командой, затем проверить обратное направление. После перезапуска виден сохранённый режим.
- Выключить бота из карточки и подать обычное сообщение. Проверить приостановку журнала и ответа. После включения возвращается прежний режим. Включённая молчаливая беседа продолжает вести журнал.
- Открыть две карточки и изменить одну беседу. Состояние соседней сохраняется. При смене поколения между открытием карточки и отправкой устаревшее действие отклоняется. Сессия другого пользователя не может применить действие.

## Что явно не входит

Возобновление подключения после паузы F3.7, сброс данных и изменение бюджета.

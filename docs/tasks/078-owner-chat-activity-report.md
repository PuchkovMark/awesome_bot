# Задача 078 — Запросы, ожидание и ошибки за выбранный период

- Номер: 078
- Название: Запросы, ожидание и ошибки за выбранный период
- Статус: черновик
- Дата: 2026-11-24
- Дата завершения: —
- Связанные документы: [F10.4 в дорожной карте](../roadmap.md#веха-10-личный-кабинет) · [Метрики F9.2](069-chat-request-metrics.md) · [Список чатов](073-owner-chat-list.md)

## Проблема или цель

Владельцу нужно понимать, сколько обращений обслуживает беседа, сколько они ждут и почему часть из них завершается отказом.

## Ожидаемое поведение

В личном кабинете владелец выбирает беседу и период. По данным F9.2 отчёт показывает число обращений, время ожидания в очереди, длительность обработки, число шагов и фактических вызовов модели, вызовы инструментов, отказы по квоте и ошибки модели. Для той же беседы и периода доступен [отчёт о расходе токенов](079-owner-chat-token-report.md).

## Критерии приёмки

- Проверить две беседы с известным числом обращений в двух периодах. При смене беседы или периода каждый показатель совпадает с независимыми счётчиками F9.2.
- Для обращения с инструментом, помощником и повторной попыткой показать одно обращение. Шаги, фактические вызовы моделей и вызовы инструментов сверить отдельно с данными задачи 069. Повторное открытие отчёта даёт те же значения при отсутствии новых событий.
- На выборке с успешным ответом, отказом до обращения к модели и ошибкой провайдера сверить раздельный подсчёт исходов. Время ожидания сверяется с контрольными значениями по согласованному для F9.2 правилу.
- После перезапуска и истечения срока трассировок повторить запрос внутри срока хранения метрик и получить те же значения. Пустой период и недоступный период различимы, если данных для сводки недостаточно.

## Что явно не входит

Создание счётчиков F9.2, индивидуальная диагностика ответов, настройка лимитов и отчёт по токенам.

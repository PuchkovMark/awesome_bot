## Проблема или цель

Схема F1.5 позволяет хранить несколько фактов о человеке. Инструментам участников и будущим карточкам нужно понимать, какой факт действует в этой беседе, откуда он взялся и кому его разрешено показывать.

## Ожидаемое поведение

Профиль принадлежит человеку в конкретной беседе или личном диалоге. Для каждого факта сохраняются значение, источник, доступные сведения о происхождении, надёжность, видимость и время. При противоречии приоритет имеет сообщение самого человека, затем запись администратора, затем вывод бота. Среди равных источников действует более новый факт. Приоритет источника сам по себе не повышает надёжность.

Запись и использование профиля учитывают доставку уведомления и действующий выбор участника по задаче 040. Для нового поля действует видимость `chat` по умолчанию. Явное ограничение сохраняется при обновлении значения. Для публичного поиска по интересу доступны только явно указанные самим человеком интересы, разрешённые к раскрытию в этом чате.

Несколько интересов участника могут действовать одновременно. Явное исправление или отказ относится к указанному интересу.

## Критерии приёмки

- На синтетических данных одного человека в двух группах и личке проверить независимые значения одного поля. После перезапуска сохраняются значение, происхождение, видимость и надёжность. У двух тёзок в одной группе остаются разные профили.
- Для однозначного поля записать несовместимые значения из трёх источников в разном порядке. Поздний вывод бота не вытесняет слова участника. Более новое сообщение самого участника меняет действующее значение. При недоступном исходном сообщении профиль не приписывает факту вымышленный источник.
- Проверить запись до доставки уведомления, после неё и после отключения профилирования. Закрытый профиль исключается из обычного использования. Доступ автора к собственной выгрузке соответствует правилам 040.
- На границе данных для 042 проверить интерес «шахматы». Участник с собственным открытым интересом входит в выборку. При видимости `bot` или `unknown` публичный результат совпадает со случаем отсутствующего интереса, в том числе для обычного администратора. Отдельно проверить вывод бота о том же увлечении. Закрытое значение нельзя восстановить из старой публичной версии поля.
- Участник называет шахматы, затем бег. Оба интереса доступны по правилам видимости. После отказа от шахмат среди актуальных остаётся бег, в том числе после перезапуска.
- После исправления, ограничения видимости или удаления публичное чтение отражает актуальное состояние. Текст значения или примечания источника, похожий на команду, не меняет права доступа.

## Что явно не входит

Команды редактирования F5.4, подбор карточек в контекст F5.5, исполнение инструментов F5.6, автоматическое извлечение и оценка давности F5.7, срок удаления после выхода F5.9. Уведомления, выгрузка и удаление всех данных человека описаны в 040.

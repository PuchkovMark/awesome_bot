- Статус: выполнено

- Дата завершения: 2026-11-23
- Связанные документы: [план фичи](../../plans/completed/045-new-member-greeting.md), [F8.4 в дорожной карте](../../roadmap.md#веха-8-знакомство), [реестр участников 039](039-participant-registry.md), [шаблон анкеты 044](../044-legacy-introduction-questionnaire.md).

## Проблема или цель

Когда человек входит в беседу, администратор бота хочет поприветствовать его от имени бота. Реестр уже учитывает подтверждённое участие. Первичное получение списка, повтор события VK и повторная сверка состава сами по себе не свидетельствуют о новом вступлении.

## Ожидаемое поведение

Приветствие по умолчанию выключено. Администратор бота может включить его для своей беседы. После подтверждённого вступления бот публикует приветствие в той же беседе. Для нескольких участников, вступивших вместе, предусмотрена одна общая реплика. Текст учитывает выбранный шаблон приветствия, персонажа и доступные правила беседы. Из профиля можно использовать только сведения, разрешённые к публичному использованию в этой беседе.

Когда анкету можно пройти в этой беседе, приветствие может содержать одну строку с предложением её заполнить. До появления доступной анкеты приветствие самостоятельно. При возвращении с сохранённым профилем повторное приглашение к анкете исключено. У автозапуска анкеты отдельная настройка.

## Критерии приёмки

- Добавить бота в существующую тестовую беседу и получить первый полный список. Для прежних участников отправлено ноль приветствий. Проверить это также при восстановлении связи без подтверждённых новых вступлений.
- В двух беседах включить приветствие только в одной. При входе одного и того же человека по ссылке ровно одна публикация появляется в выбранной беседе. Участник без прав администратора бота не может изменить настройку.
- При добавлении по приглашению или неоднозначном событии проверить две последовательности. Если сверка подтвердила вход конкретного человека, он получает приветствие. При неполном списке без подтверждения входа сообщений нет.
- После успешной отправки повторить событие, перезапустить приложение и повторить сверку. Второе приветствие тому же человеку за тот же вход не отправляется. При массовом входе отправляется одно общее сообщение.
- На примере шаблона, персонажа, правила беседы и закрытого поля профиля проверить текст публикации. Закрытый факт не раскрывается ни прямо, ни пересказом. Приветствие работает и для человека без профиля.
- При выключенном боте отправок нет. Пока анкету нельзя пройти, приглашений заполнить её нет. После подключения анкеты проверить отдельные случаи первого входа и возвращения с сохранённым профилем.

## Что явно не входит

Список вопросов, прохождение анкеты, запись ответов в профиль и публичное представление участника по его ответам относятся к другим задачам вехи F8. Служебное вступление при подключении самого бота регулируется F3.6.

## Согласованные правила

2026-11-23 владелец утвердил задачу и три правила.

- При одиночном входе базовый текст — «Привет, {имя}! Добро пожаловать в беседу!», при массовом — «Всем привет! Добро пожаловать в беседу!».
- При одиночном возвращении с сохранённым профилем — «С возвращением, {имя}!» без повторного предложения анкеты.
- Окно объединения — 30 секунд от первого подтверждённого входа. Одиночное приветствие также отправляется по окончании окна.

## Проблема или цель

После разрыва связи несколько бесед могут одновременно перейти в `uncertain`. Уже есть решение по известному идентификатору беседы через `resolve-chat`. Владельцу нужно находить все подключения, требующие решения, понимать причину и выбирать действие для каждой беседы.

## Ожидаемое поведение

Владелец получает служебный обзор с идентификатором каждой беседы, причиной паузы и последствиями обоих действий. Продолжение сохраняет историю текущего подключения. Начало нового подключения очищает данные прежнего поколения по действующим правилам жизненного цикла. Сам просмотр сохраняет паузу. F3.4 завершена, обзор можно предоставить через существующий административный путь до появления веб-кабинета.

## Критерии приёмки

- На стенде с десятью приостановленными беседами и одной действующей владелец находит ровно десять требующих решения. При пустом списке он получает явный ответ.
- До выбора видны причина паузы, целевая беседа и последствия для истории. В обзоре отсутствуют тексты переписки. Право на межчатовый обзор ограничено владельцем.
- Владелец продолжает одну беседу с сохранением истории. Для второй начинает новое подключение и проверяет очистку старого поколения. Остальные восемь остаются на паузе, действующая беседа продолжает работать.
- После перезапуска обзор отражает сохранённые решения. Повтор команды для устаревшего подключения сохраняет новое поколение и его данные. При неопределённости обычный приём остаётся приостановленным до решения.

## Что явно не входит

Веб-интерфейс F9.6–F9.7, массовый сброс бесед, восстановление из резервной копии.

# Задача 048 — Автообновление профилей из переписки

- Номер: 048
- Название: Автообновление профилей из переписки
- Статус: в работе
- Дата: 2026-11-23
- Дата завершения: —
- Связанные документы: [план реализации](../impl-plans/048-automatic-profile-updates.md), [план фичи](../plans/048-automatic-profile-updates.md), [F5.7 в дорожной карте](../roadmap.md#веха-5-участники-и-профили).

## Проблема или цель

Бот должен использовать новые сведения, которые появляются в разговоре, сохраняя за участником возможность увидеть и отклонить вывод о себе.

## Ожидаемое поведение

После доставки действующего уведомления бот сам выбирает факты из последующей переписки своей беседы. Для вывода доступны его происхождение и давность. Приоритет источников по убыванию — сам человек, администратор бота, вывод бота. Среди равных источников действует более новый факт. Старение уменьшает вес факта.

Обработка идёт в фоне небольшими порциями с отдельным лимитом внутри бюджета беседы. Через 90 дней без нового свидетельства вывод теряет вес. После отклонения основанием для повторного вывода может стать только новое явное сообщение самого человека о себе.

## Критерии приёмки

- Сравнить сообщения до доставки уведомления и после неё, а также сообщение после отказа участника от профилирования. Для автообновления допускается только сообщение после доставки при действующем разрешении. Аналогично проверить личный диалог.
- На двух одноимённых участниках и двух беседах проверить автора, предмет вывода и привязку к исходной переписке. Вывод хранится как вывод бота. Текст цитаты с просьбой изменить чужой профиль не даёт полномочий.
- Вывод, противоречащий действующей записи самого человека или администратора, не вытесняет её. Повтор обработки того же сообщения не создаёт второй факт.
- Участник может увидеть и отклонить вывод. Повторная обработка прежнего источника не возвращает отклонённое сведение. Состарившийся факт помечается и получает меньший вес без автоматического удаления только по давности.

## Что явно не входит

Анкета знакомства, сбор данных из соседних чатов и разработка пользовательских команд задачи 046.

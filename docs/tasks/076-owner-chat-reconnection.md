# Задача 076 — Продолжение или сброс приостановленной беседы из кабинета

- Связанные документы: [F10.3 в дорожной карте](../roadmap.md#веха-10-личный-кабинет) · [Список приостановленных подключений](073-owner-chat-list.md)

## Проблема или цель

Владельцу нужно разрешать неопределённость подключения из карточки конкретной группы VK с теми же последствиями, что и при использовании штатных команд F3.7.

## Ожидаемое поведение

Владелец может продолжить текущее подключение с его историей и настройками либо начать новое. Перед сбросом кабинет показывает выбранную беседу и последствия для её данных.

## Критерии приёмки

- Для приостановленной группы выполнить «Продолжить» и сверить результат с F3.7. Поколение, доступная история и настройки сохраняются, причина паузы снимается.
- Для другого сценария проверить предупреждение перед сбросом. При отказе данные сохраняются. После подтверждения очищается прежнее поколение выбранной беседы, начинается новое подключение. В соседней беседе сохраняются прежние данные.
- Между открытием карточки и подтверждением изменить ревизию или поколение. Устаревшее решение не применяется. Повтор уже принятого решения не создаёт ещё одного поколения. Проверить отказ пользователю без прав владельца.

## Что явно не входит

Принятие решения о продолжении автоматически, обычное включение бота и восстановление назначения локального администратора.

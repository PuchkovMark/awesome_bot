## Подход и ключевые решения

Участник вызывает `/профиль` в группе и получает в личке подписанный названием беседы список собственных фактов. В личке команда без аргумента открывает профиль самого диалога, а с ID беседы — профиль автора в указанной беседе по правилам F5.8. Для пустого собственного профиля достаточно короткого сообщения. Если личное сообщение из группового сценария доставить нельзя, в группе появляется подсказка, как начать диалог с сообществом. Она не содержит фактов или признаков наличия конкретного поля.

Личный список показывает значение, источник и видимость каждого действующего факта, включая скрытые самим участником. У каждой позиции свой номер. Участник отвечает на сообщение со списком одной командой:

- `/исправить 2 новое значение` сохраняет собственное утверждение участника и действующее ограничение видимости. Для многозначного поля меняется только выбранная позиция.
- `/скрыть 2` ограничивает публичную видимость выбранного сведения по правилам F5.3. При следующем публичном чтении это ограничение действует и для поиска.
- `/отклонить 2` снимает выбранный действующий вывод бота. Для источника «участник» или «администратор» команда возвращает пояснение. Для полного удаления данных участнику доступна действующая процедура F5.8 с личным подтверждением.

Харнес обрабатывает команды как персональные служебные действия без вызова модели. Основанием изменения служат подтверждённые автор и личный диалог, ответ на конкретное доставленное ботом сообщение и актуальное состояние выбранной позиции. Перед записью проверяются допуск, поколение беседы и действующая версия факта. Отказ, подмена номера или устаревший список дают безопасную подсказку открыть профиль заново. Исправленное значение не попадает в групповой ответ, поиск по истории или контекст модели через текст команды.

## Альтернативы и причина выбора

Личная доставка уже знакома по команде выгрузки данных и позволяет показать владельцу закрытые поля. Выбор по номеру в ответе на список позволяет различать несколько интересов с одинаковым названием поля. Участнику не приходится копировать текст факта или технический ID.

## Изменения спецификаций

В [командах](../../specs/commands-and-limits.md) потребуется описать синтаксис и выбор области. В [профилях](../../specs/profiles.md) — личное представление и результат трёх действий. В [приватности](../../specs/privacy.md) и [хранилище](../../specs/storage.md) — защиту служебного ввода и срок жизни привязок списка. Публичная карточка 042 продолжает учитывать видимость для аудитории беседы.

## Влияние на контракты и данные

Публичное чтение F5.3 отбирает поля для аудитории беседы. Для списка нужен отдельный доступ человека к своим действующим фактам в проверенной области. Для правки из лички требуется подтвердить личное действие над выбранной областью: идентификатор личного сообщения сам по себе не является сообщением группы. Изменения сохраняют правила источников, видимости и удаления F5.3/F5.8.

В БД достаточно сохранить привязку доставленного списка к получателю, беседе, поколению и версиям показанных позиций без второй копии их значений. При переключении беседы прежний список теряет силу. Повтор события после перезапуска не применяет правку дважды. При удалении данных или подключения привязка перестаёт разрешать действия.

## Риски и приёмка

На временной SQLite с подменой VK проверить одного человека в двух беседах и двух тёзок в одной. Проверить отсутствие личных данных в группе при запрете доставки, отказ при ответе на пересланный или устаревший список, два интереса в одном профиле и повтор команды после перезапуска. В гонке скрытия и публикации использовавшая поле карточка должна утратить актуальность. Отдельно проверить отклонение существующего вывода бота и прежнее личное подтверждение полного удаления. Анкета для этих сценариев не требуется.

## Допущения

Для проверки достаточно имеющихся фактов F5.3. В будущем сохранённые факты анкеты F8.5 смогут использовать тот же просмотр. Разбиение длинных списков по ограничениям VK и очистку служебных привязок следует конкретизировать в плане реализации.

# A02. Подчинить generate_image решению active-режима и единственности действия

**Приоритет:** P1. **Вид:** Исправление защищённого побочного эффекта. **Дата:** 19.11.2026.
**Статус:** задача и план предложены; реализация не начата, выборы D* остаются открытыми.
**Основание:** [находка A02 аудита](../../../project-issues/specification-audit.md#a02-p1--решение-active-режима-и-единственность-действия-не-распространяются-на-генерацию-изображения); [предложенный план](plan.md); [общий реестр](../../../project-issues/specification-audit-tasks.md).

## Проблема и проверенное текущее поведение

`getActionError` и `beginAction` уже реализуют ограничения соседних tools. `createImageTool` получает только `checkToolAccess`, не занимает слот и сам отправляет фото.

Канонические контракты: [tools.md#generate_image](../../project/src/services/ai/tools.md#generate_image), [tools.md#decide_chat_response](../../project/src/services/ai/tools.md#decide_chat_response), [vkService.md#ai-инструменты-действия-и-доставка](../../project/src/services/vk/vkService.md#ai-инструменты-действия-и-доставка).
Релевантные участки текущего рабочего дерева проверены статически. Само наличие записи в аудите не означает воспроизведение инцидента; выполненные ранее тесты не считаются выполненными заново.

## Предлагаемый результат

Генерация и редактирование не начинаются до положительного active-decision и не следуют за уже начатым несовместимым действием.

Для вопросов категории Q требуется сначала выбрать контракт; гипотеза не объявляется подтверждённым дефектом. Рекомендации плана не являются принятыми пользовательскими решениями.

## Область и ограничения

- [getActionError / beginAction / подключение imageTool](../../../src/services/vk/vkService.ts) — владелец затронутого исполнения/данных.
- [createImageTool](../../../src/services/ai/tools/imageTool.ts) — владелец затронутого исполнения/данных.

Текущая JSON Schema, поиск фото current/reply, статусы валидации, подсчёт image_generate/image_edit и подавление второго ответа после доставки.

Новые пользовательские функции, команды и инструменты не добавляются. Сейчас разрешена подготовка задачи и предложения плана; изменение приложения, общей спецификации и запуск реализации этим документом не разрешены. Предыдущие незакоммиченные изменения сохраняются.

## Критерии приёмки предлагаемого результата

- **AC-1:** До `respond=true`, после `respond=false`, чтения VK-сведений, команды или попытки доставки генератор и отправитель не вызываются.
- **AC-2:** Допустимое изображение занимает общий слот ровно один раз до платной генерации; второй конфликтующий tool отклоняется.
- **AC-3:** Отсутствующее фото, неверные аргументы и недоступная конфигурация возвращают существующие статусы согласно выбранной точке занятия слота.
- **AC-4:** При исключении после начала операции слот не освобождается для автоматического повтора потенциально выполненного действия.

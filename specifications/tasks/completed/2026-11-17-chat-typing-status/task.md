# Индикатор активности в беседах VK

Пользователь поручил исправить отсутствие индикатора печатания в беседах после диагностики и предложения передавать `group_id` также для бесед.

Основание: [VkService](../../../project/src/services/vk/vkService.md), [исходный код](../../../../src/services/vk/vkService.ts). В контейнере подтверждён текущий код: `startActivity` исключает `group_id` для peer бесед. В журнале обнаружены 11 отказов `922` для `2000000004`; для двух остальных бесед аналогичные ошибки не подтверждены. Причинная связь с отсутствующим параметром требует проверки в VK.

- AC-1: при известном ID сообщества запрос активности содержит `group_id` для бесед и ЛС; исходные `peer_id` и `type` сохраняются.
- AC-2: при отсутствии ID сообщества параметр не добавляется; интервал, остановка, защита от параллельных запросов и обработка ошибок сохраняются.
- AC-3: исправление проверено изолированно; контейнер приложения пересобран и перезапущен без миграций. Видимость в трёх беседах подтверждается отдельно в клиенте VK.

Область: параметры общего `startActivity`, существующие проверки и применение исправления. Новые тестовые файлы, права, очередь, конфигурация, БД и синхронизация общих спецификаций не входят в задачу. Вызовы живого VK ради проверки не выполнять.

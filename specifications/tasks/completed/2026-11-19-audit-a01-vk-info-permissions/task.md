# A01. Согласовать права чтения и выдачи сведений VK

**Приоритет:** P2. **Вид:** Поведенческое исправление после выбора матрицы прав. **Дата:** 19.11.2026.
**Статус:** задача и план предложены; реализация не начата, выборы D* остаются открытыми.
**Основание:** [находка A01 аудита](../../../../project-issues/specification-audit.md#a01-p2--сведения-vk-доступны-участнику-на-входе-и-запрещены-при-выдаче-ответа); [предложенный план](plan.md); [общий реестр](../../../../project-issues/specification-audit-tasks.md).

## Проблема и проверенное текущее поведение

`createChatInfoTool` разрешает ряд действий обычному участнику, но `VkService` после `onInfoReturned` запрещает любой групповой результат без глобальной роли. Факт проверен в обработчике tools и финальной доставке; это несогласованность двух проверок.

Канонические контракты: [tools.md#get_chat_info](../../../project/src/services/ai/tools.md#get_chat_info), [vkService.md#ai-инструменты-действия-и-доставка](../../../project/src/services/vk/vkService.md#ai-инструменты-действия-и-доставка).
Релевантные участки текущего рабочего дерева проверены статически. Само наличие записи в аудите не означает воспроизведение инцидента; выполненные ранее тесты не считаются выполненными заново.

## Предлагаемый результат

Одно действие `get_chat_info` имеет одинаковые права перед VK API и перед выдачей результата. Глобальный административный запрет не подменяет проверку выбранного действия.

Для вопросов категории Q требуется сначала выбрать контракт; гипотеза не объявляется подтверждённым дефектом. Рекомендации плана не являются принятыми пользовательскими решениями.

## Область и ограничения

- [createChatInfoTool / ChatInfoContext](../../../../src/services/ai/tools/chatInfoTool.ts) — владелец затронутого исполнения/данных.
- [checkToolAccess / onInfoReturned / финальная доставка](../../../../src/services/vk/vkService.ts) — владелец затронутого исполнения/данных.

ЛС ограничены своим пользователем; `membership` не раскрывает персональные события; active/quiet/maintenance и запрет последующих конфликтующих действий сохраняются.

Новые пользовательские функции, команды и инструменты не добавляются. Сейчас разрешена подготовка задачи и предложения плана; изменение приложения, общей спецификации и запуск реализации этим документом не разрешены. Предыдущие незакоммиченные изменения сохраняются.

## Критерии приёмки предлагаемого результата

- **AC-1:** Для каждого action зафиксирована матрица «участник / администратор беседы / администратор бота / создатель × ЛС / группа»; до выбора D1 матрица не считается утверждённой.
- **AC-2:** Запрещённый actor не вызывает VK API; разрешённый получает соответствующий результат вместо общего административного отказа.
- **AC-3:** Отзыв нужной роли до выдачи блокирует только результат, требующий этой роли, включая несколько tool calls с разными требованиями в одном ответе.
- **AC-4:** Условия active/quiet/maintenance и персональная изоляция не ослаблены.

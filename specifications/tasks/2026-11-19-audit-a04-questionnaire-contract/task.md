# A04. Уточнить действующий синтаксис и размеры анкеты

**Приоритет:** P2. **Вид:** Исправление документации существующего поведения. **Дата:** 19.11.2026.
**Статус:** задача и план предложены; реализация не начата.
**Основание:** [находка A04 аудита](../../../project-issues/specification-audit.md#a04-p2--управление-вопросами-анкеты-и-допустимый-размер-описаны-по-разному); [предложенный план](plan.md); [общий реестр](../../../project-issues/specification-audit-tasks.md).

## Проблема и проверенное текущее поведение

`CommandService.setQuestionnaire` принимает только on/off; MemberService использует пределы 32 вопроса, 200 на вопрос, 500 на ответ, 3500 на одно сообщение. README обещает set и предел 8.

Канонические контракты: [commands.md#command-questionnaire](../../project/src/services/command/commands.md#command-questionnaire), [memberService.md#два-режима-анкеты](../../project/src/services/member/memberService.md#два-режима-анкеты), [memberService.md#разбор-шаблона-и-пошаговый-ответ](../../project/src/services/member/memberService.md#разбор-шаблона-и-пошаговый-ответ).
Релевантные участки текущего рабочего дерева проверены статически. Само наличие записи в аудите не означает воспроизведение инцидента; выполненные ранее тесты не считаются выполненными заново.

## Предлагаемый результат

Пользовательская справка и канонические контракты согласованно описывают уже исполняемый синтаксис и совокупный бюджет формы.

Для вопросов категории Q требуется сначала выбрать контракт; гипотеза не объявляется подтверждённым дефектом. Рекомендации плана не являются принятыми пользовательскими решениями.

## Область и ограничения

- [CommandService.setQuestionnaire](../../../src/services/command/commandService.ts) — владелец затронутого исполнения/данных.
- [MAX_QUESTIONNAIRE_QUESTIONS / answerQuestionnaire](../../../src/services/member/memberService.ts) — владелец затронутого исполнения/данных.
- [описание /опрос](../../../README.md) — относящийся документ.
- [command-questionnaire](../../project/src/services/command/commands.md) — относящийся документ.
- [два режима анкеты и разбор формы](../../project/src/services/member/memberService.md) — относящийся документ.

Не добавлять /опрос set и не уменьшать/увеличивать runtime-лимиты в рамках исправления текста; старые вопросы/профили и открытые анкеты сохраняются.

Новые пользовательские функции, команды и инструменты не добавляются. Сейчас разрешена подготовка задачи и предложения плана; изменение приложения, общей спецификации и запуск реализации этим документом не разрешены. Предыдущие незакоммиченные изменения сохраняются.

## Критерии приёмки предлагаемого результата

- **AC-1:** Во всех описаниях текущей команды указаны поддерживаемые on/off; недействующий set не объявлен исполняемым.
- **AC-2:** Пределы 32/200/500/3500 описаны как текущие ограничения, а не как обещание одновременного заполнения всех полей до максимума.
- **AC-3:** Объяснено действие общего лимита и существующих средств редактирования без потери уже сохранённых ответов.
- **AC-4:** Ссылки, примеры и права групповой команды согласованы; исходный код, схема и сохранённые анкеты не меняются.

## Решения и зависимости

Зависимостей от других находок аудита нет; ограничения текущих контрактов сохраняются.
Новых вариантов поведения для выбора не требуется: исправляется описание уже проверенного исполнения.
Согласовано текущим запросом только создание отдельных задач и предложений планов. Существующие явно принятые решения связанных задач не переоткрываются. Согласование вопросов — последовательно, по одному, без автоматического выбора.

## Граница завершения

Задача завершена после выполнения выбранного варианта, проверки всех AC и необходимого обновления её канонических контрактов. На этапе планирования это ещё не произошло. Для реализации после разрешения открытых решений требуется подробная детализация по [awesome-bot-implementation-plan](../../../.agents/skills/awesome-bot-implementation-plan/SKILL.md). Предыдущие планы и ревью не перезаписывать.

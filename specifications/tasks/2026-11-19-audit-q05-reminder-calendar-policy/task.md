# Q05. Уточнить календарные границы напоминаний и детерминировать DST

**Приоритет:** P2. **Вид:** Уточнение календарных требований. **Дата:** 19.11.2026.
**Статус:** задача и план предложены; реализация не начата, выборы D* остаются открытыми.
**Основание:** [находка Q05 аудита](../../../project-issues/specification-audit.md#q05-p2--календарные-напоминания-не-имеют-однозначных-правил-для-dst-переноса-и-возобновления); [предложенный план](plan.md); [общий реестр](../../../project-issues/specification-audit-tasks.md).

## Проблема и проверенное текущее поведение

toUtcDateTime возвращает достигнутый итерациями instant; fold/gap не имеют полной пользовательской политики. Resume может назначить now+1min, move не пересчитывает recurrenceEndAt.

Канонические контракты: [reminderDateTime.md#часовой-пояс](../../project/src/services/reminders/reminderDateTime.md#часовой-пояс), [reminderDateTime.md#календарные-операции](../../project/src/services/reminders/reminderDateTime.md#календарные-операции), [reminderService.md#просмотр-выбор-и-управление](../../project/src/services/reminders/reminderService.md#просмотр-выбор-и-управление).
Релевантные участки текущего рабочего дерева проверены статически. Само наличие записи в аудите не означает воспроизведение инцидента; выполненные ранее тесты не считаются выполненными заново.

## Предлагаемый результат

Те же локальные дата/время/зона дают предсказуемый результат; pause/resume/move не обходят явно выбранную конечную дату и правила повтора.

Для вопросов категории Q требуется сначала выбрать контракт; гипотеза не объявляется подтверждённым дефектом. Рекомендации плана не являются принятыми пользовательскими решениями.

## Область и ограничения

- [toUtcDateTime / getNextRecurringDate / resolveReminderTimeZone](../../../src/services/reminders/reminderDateTime.ts) — владелец затронутого исполнения/данных.
- [parseReminder / recurrenceEndAt](../../../src/services/reminders/reminderParser.ts) — владелец затронутого исполнения/данных.
- [handleManagement / nextOccurrence / completeOccurrence](../../../src/services/reminders/reminderService.ts) — владелец затронутого исполнения/данных.

Личная зона автора и общая зона беседы остаются раздельными; интервал — длительность, календарный повтор — локальное время. Новая библиотека дат и новый timezone-переключатель не вводятся по умолчанию.

Новые пользовательские функции, команды и инструменты не добавляются. Сейчас разрешена подготовка задачи и предложения плана; изменение приложения, общей спецификации и запуск реализации этим документом не разрешены. Предыдущие незакоммиченные изменения сохраняются.

## Критерии приёмки предлагаемого результата

- **AC-1:** Выбрана политика повторяющегося и несуществующего локального времени; результат не зависит от случайной сходимости итераций.
- **AC-2:** Для pause/resume/move установлен результат до/на/после recurrenceEndAt; перенос не создаёт недостижимую активную запись.
- **AC-3:** Пропущенные календарные и интервальные occurrence следуют выбранному правилу без бесконтрольного воспроизведения backlog.
- **AC-4:** Месячные/годовые границы, fallback Москвы и источник зоны согласованы с уже описанными scope.

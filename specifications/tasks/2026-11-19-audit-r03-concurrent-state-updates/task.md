# R03. Предотвратить потерю общего состояния при параллельных командах

**Приоритет:** P1. **Вид:** Исправление конкурентных записей. **Дата:** 19.11.2026.
**Статус:** задача и план предложены; реализация не начата, выборы D* остаются открытыми.
**Основание:** [находка R03 аудита](../../../project-issues/specification-audit.md#r03-p1--параллельные-slash-команды-не-согласованы-с-изменением-общего-состояния); [предложенный план](plan.md); [общий реестр](../../../project-issues/specification-audit-tasks.md).

## Проблема и проверенное текущее поведение

Slash-команды не сериализованы; AdventureService.save безусловно перезаписывает JSON, ряд lifecycle/настроек обходят lock. answerQuestionnaire записывает ответы без проверки устаревшего draft/профиля.

Канонические контракты: [adventureService.md#конкурентность-и-атомарность](../../project/src/services/games/adventureService.md#конкурентность-и-атомарность), [memberService.md#ограничения-и-тестовые-свидетельства](../../project/src/services/member/memberService.md#ограничения-и-тестовые-свидетельства), [requestQueue.md](../../project/src/services/queue/requestQueue.md).
Релевантные участки текущего рабочего дерева проверены статически. Само наличие записи в аудите не означает воспроизведение инцидента; выполненные ранее тесты не считаются выполненными заново.

## Предлагаемый результат

Два успешных действия не затирают друг друга; устаревший AI-ход или шаблон обнаруживает конфликт. Slash остаётся вне пользовательской очереди.

Для вопросов категории Q требуется сначала выбрать контракт; гипотеза не объявляется подтверждённым дефектом. Рекомендации плана не являются принятыми пользовательскими решениями.

## Область и ограничения

- [save / advance / handleCommand / recordImage / start](../../../src/services/games/adventureService.ts) — владелец затронутого исполнения/данных.
- [startQuestionnaire / answerQuestionnaire / updateProfileAnswer](../../../src/services/member/memberService.ts) — владелец затронутого исполнения/данных.
- [выбор обхода RequestQueue](../../../src/services/vk/vkService.ts) — владелец затронутого исполнения/данных.
- [GameSession / ConversationMember](../../../prisma/schema.prisma) — владелец затронутого исполнения/данных.

Решение старой slash-задачи: не возвращать глобальное ожидание пользовательской очереди. Не держать SQLite-транзакцию на время AI; сохранять права ведущего, профили и историю.

Новые пользовательские функции, команды и инструменты не добавляются. Сейчас разрешена подготовка задачи и предложения плана; изменение приложения, общей спецификации и запуск реализации этим документом не разрешены. Предыдущие незакоммиченные изменения сохраняются.

## Критерии приёмки предлагаемого результата

- **AC-1:** Ход вместе с settings/character/pause/end не затирает подтверждённое изменение; исход конфликта явный.
- **AC-2:** Сохранение устаревшей формы не отменяет последующую правку профиля без сообщения о конфликте.
- **AC-3:** Параллельные start не создают несколько допустимых активных adventure-сессий одной беседы; межпроцессная гарантия сформулирована явно.
- **AC-4:** Остальные slash-команды продолжают стартовать без ожидания модели; миграция не удаляет старые сессии/профили молча.

## Решения и зависимости

Зависимостей от других находок аудита нет; ограничения текущих контрактов сохраняются.
Не приняты решения: `R03-D1`, `R03-D2`, `R03-D3`. Варианты, рекомендация и зависимые шаги указаны в [плане](plan.md#открытые-решения).
Согласовано текущим запросом только создание отдельных задач и предложений планов. Существующие явно принятые решения связанных задач не переоткрываются. Согласование вопросов — последовательно, по одному, без автоматического выбора.

**Приоритет:** P2. **Вид:** Исправление атомарности существующего действия. **Дата:** 19.11.2026.
**Статус:** задача и план предложены; реализация не начата, выборы D* остаются открытыми.
**Основание:** [находка A06 аудита](../../../project-issues/specification-audit.md#a06-p2--каталог-данных-обещает-атомарную-дедупликацию-которой-нет-у-ai-действий-приключения-и-баттла); [предложенный план](plan.md); [общий реестр](../../../project-issues/specification-audit-tasks.md).

## Проблема и проверенное текущее поведение

GameInteractionService.handle создаёт GameEvent для adventure/battle до вызова движка. AdventureService сохраняет JSON отдельно, battle исполняется через CommandService. Каталог моделей обобщает атомарный commit обычных игр.

Канонические контракты: [gameInteractionService.md#разрешение-текущей-игры-и-дедупликация](../../project/src/services/games/gameInteractionService.md#разрешение-текущей-игры-и-дедупликация), [gameService.md#транзакции-таймауты-и-уход-участника](../../project/src/services/games/gameService.md#транзакции-таймауты-и-уход-участника), [models.md#gameevent](../../project/prisma/models.md#gameevent), [models.md#транзакционные-границы](../../project/prisma/models.md#транзакционные-границы).
Релевантные участки текущего рабочего дерева проверены статически. Само наличие записи в аудите не означает воспроизведение инцидента; выполненные ранее тесты не считаются выполненными заново.

## Предлагаемый результат

Сбой до сохранения не оставляет ложную отметку успешно выполненного действия; повтор подтверждённого события не меняет сцену и очки второй раз.

Для вопросов категории Q требуется сначала выбрать контракт; гипотеза не объявляется подтверждённым дефектом. Рекомендации плана не являются принятыми пользовательскими решениями.

## Критерии приёмки предлагаемого результата

- **AC-1:** Подтверждённо откатившееся действие не оставляет GameEvent, запрещающий его допустимую повторную обработку.
- **AC-2:** Событие, состояние и связанные очки одного успешно выполненного действия фиксируются согласованно для adventure и battle.
- **AC-3:** Повтор того же события после commit не продвигает сцену и не начисляет очки повторно; при неопределённом исходе нет обещания безопасного повтора.
- **AC-4:** Каталог данных точно различает гарантии adapter, обычных игр, мафии и приключения.

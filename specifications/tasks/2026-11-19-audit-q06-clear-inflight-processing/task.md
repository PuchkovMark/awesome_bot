# Q06. Определить границу очистки при уже выполняющейся обработке

**Приоритет:** P2. **Вид:** Уточнение очистки и производных данных; восстановление не воспроизведено. **Дата:** 19.11.2026.
**Статус:** задача и план предложены; реализация не начата, выборы D* остаются открытыми.
**Основание:** [находка Q06 аудита](../../../project-issues/specification-audit.md#q06-p2--очистка-данных-не-описывает-взаимодействие-с-уже-выполняющейся-обработкой); [предложенный план](plan.md); [общий реестр](../../../project-issues/specification-audit-tasks.md).

## Проблема и проверенное текущее поведение

clearUserHistory удаляет Message выбранного автора/peer; явная очистка памяти удаляет LongTermMemory, а captureAutomatically работает fire-and-forget. Прямой пересказ хранит уже прочитанные сообщения/выжимки в процессе.

Канонические контракты: [commands.md#command-reset](../../project/src/services/command/commands.md#command-reset), [commands.md#command-forget](../../project/src/services/command/commands.md#command-forget), [longTermMemoryService.md#автоматическое-сохранение](../../project/src/services/memory/longTermMemoryService.md#автоматическое-сохранение), [longTermMemoryService.md#явное-управление](../../project/src/services/memory/longTermMemoryService.md#явное-управление), [directSubagentService.md#обработка](../../project/src/services/ai/directSubagentService.md#обработка).
Релевантные участки текущего рабочего дерева проверены статически. Само наличие записи в аудите не означает воспроизведение инцидента; выполненные ранее тесты не считаются выполненными заново.

## Предлагаемый результат

Подтверждение очистки точно описывает область и последствия для старой выполняющейся работы; позднее завершение не нарушает выбранную границу.

Для вопросов категории Q требуется сначала выбрать контракт; гипотеза не объявляется подтверждённым дефектом. Рекомендации плана не являются принятыми пользовательскими решениями.

/forget не становится удалением всего аккаунта. Профили, напоминания, игры и чужие данные не удаляются; уже начатый VK send нельзя объявить отменённым. Различать личную историю, общую историю и долговременные факты.

Новые пользовательские функции, команды и инструменты не добавляются. Сейчас разрешена подготовка задачи и предложения плана; изменение приложения, общей спецификации и запуск реализации этим документом не разрешены. Предыдущие незакоммиченные изменения сохраняются.

## Критерии приёмки предлагаемого результата

- **AC-1:** Выбрана таблица областей reset/forget/очистки фактов и их взаимодействия с extraction, snapshot и поздней доставкой.
- **AC-2:** После подтверждения очистки старый extraction не восстанавливает очищенную область вопреки выбранной политике; новые разрешённые сообщения обрабатываются отдельно.
- **AC-3:** Старый пересказ/ответ после очистки либо запрещён до начала send, либо завершён с явно согласованным ограничением; результат уже начатой внешней отправки не маскируется как отмена.
- **AC-4:** Очистка одного пользователя/peer не отменяет чужую работу и не удаляет данные вне заявленной области; поведение после рестарта определено.

# A05. Разделить текущий прямой пересказ и старый фоновый путь в документации

**Приоритет:** P2. **Вид:** Исправление устаревшего описания. **Дата:** 19.11.2026.
**Статус:** задача и план предложены; реализация не начата.
**Основание:** [находка A05 аудита](../../../project-issues/specification-audit.md#a05-p2--текущий-и-прежний-пути-субагента-конкурируют-за-описание-основного-сценария); [предложенный план](plan.md); [общий реестр](../../../project-issues/specification-audit-tasks.md).

## Проблема и проверенное текущее поведение

Текущий VK создаёт createSubagentTool с runDirect; SubagentService.md продолжает называть основным фоновый запуск через estimate/startJob. get_subagent_status читает только сохранённые DigestJob.

Канонические контракты: [subagentService.md#входы-и-регистрация](../../project/src/services/ai/subagentService.md#входы-и-регистрация), [tools.md#run_subagent](../../project/src/services/ai/tools.md#run_subagent), [tools.md#get_subagent_status](../../project/src/services/ai/tools.md#get_subagent_status), [directSubagentService.md](../../project/src/services/ai/directSubagentService.md).
Релевантные участки текущего рабочего дерева проверены статически. Само наличие записи в аудите не означает воспроизведение инцидента; выполненные ранее тесты не считаются выполненными заново.

## Предлагаемый результат

Каждый документ указывает фактического владельца текущего вызова и пределы старого status/delivery без восстановления старого маршрута.

Для вопросов категории Q требуется сначала выбрать контракт; гипотеза не объявляется подтверждённым дефектом. Рекомендации плана не являются принятыми пользовательскими решениями.

## Критерии приёмки предлагаемого результата

- **AC-1:** Старый сервис нигде не назван текущим основным VK-маршрутом; ссылки ведут на DirectSubagentService.
- **AC-2:** Описано, что get_subagent_status не отслеживает прямой вызов и может показывать старую задачу беседы.
- **AC-3:** Согласованные поздние решения истории не заменены ранними требованиями о фоне, лимите или обязательном частичном результате по timeout.
- **AC-4:** Исполнение, БД, конфигурация и документы завершённых задач не изменены.

## Решения и зависимости

Зависимостей от других находок аудита нет; ограничения текущих контрактов сохраняются.
Новых вариантов поведения для выбора не требуется: исправляется описание уже проверенного исполнения.
Согласовано текущим запросом только создание отдельных задач и предложений планов. Существующие явно принятые решения связанных задач не переоткрываются. Согласование вопросов — последовательно, по одному, без автоматического выбора.

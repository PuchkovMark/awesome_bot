# Спецификации awesome_bot

- [Общая спецификация проекта](project/README.md) — текущее устройство, архитектура, команды, инструменты модели, данные, функции и эксплуатация.
- [Спецификации задач](tasks/README.md) — отдельные задания, требования, планы реализации и результаты ревью.

Общая спецификация хранится в `project/`, документы каждого задания — в отдельном каталоге внутри `tasks/`. После реализации задачи актуализируйте общую спецификацию по фактическому коду; планы задач не являются описанием реализованного поведения.

# Prisma client

**Тип:** модуль подключения к БД. **Источник:** [client.ts](../../../../src/db/client.ts), singleton `prisma` и `connectDb()`; [index.ts](../../../../src/db/index.ts) переэкспортирует модуль.

Клиент создаётся при импорте. `connectDb()` вызывает `$connect`, пишет успешный результат в лог, а при ошибке логирует и повторно выбрасывает исключение. Модуль не выполняет миграции и не закрывает соединение; жизненный цикл описан в [operations](../../operations.md). Используется сервисами через общий экспорт.

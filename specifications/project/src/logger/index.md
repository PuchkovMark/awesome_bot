# Структурированный logger

**Тип:** модуль логирования. **Источник:** [logger/index.ts](../../../../src/logger/index.ts), экспорт singleton `logger` на базе Pino.

Уровень консольного потока задаёт `LOG_LEVEL`; консоль форматируется `pino-pretty`. Ошибки и fatal дополнительно записываются JSON в `logs/error.log`. Файл ограничен 5 МиБ, поддерживаются три ротации; ошибка ротации не должна останавливать приложение. Каталог создаётся синхронно при импорте. Не передавайте токены или приватный текст сообщений: структурированные поля попадают в лог.

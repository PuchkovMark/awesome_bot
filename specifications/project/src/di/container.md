# Container

**Тип:** контейнер зависимостей. **Источник:** [container.ts](../../../../src/di/container.ts), `Container` и singleton `container`.

`register(key, factory)` сохраняет фабрику по строковому ключу; повторная регистрация заменяет её. `resolve<T>(key)` возвращает закэшированный экземпляр либо создаёт и кэширует его; неизвестный ключ вызывает `Error`. Тип `T` не проверяется во время исполнения. `clear()` удаляет фабрики и кэш. Singleton не управляет scopes и очисткой ресурсов.

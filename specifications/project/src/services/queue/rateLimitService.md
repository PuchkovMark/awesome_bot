# RateLimitService

**Тип:** сервис ограничения частоты. **Источник:** [rateLimitService.ts](../../../../../src/services/queue/rateLimitService.ts), класс `RateLimitService(limit, windowMs, maxTrackedUsers = 10000)`.

`take(userId, now = Date.now(), notifyOnLimit = true)` удаляет из окна отметки возраста `>= windowMs`. Если оставшихся запросов меньше `limit`, добавляет текущую отметку и возвращает `{ allowed: true, retryAfterMs: 0, notify: false }`. Иначе отметка запроса не добавляется; возвращается `allowed: false`, время до выхода самой ранней отметки из окна, минимум 1 мс, и признак уведомления. Уведомление одному пользователю ограничено одним на окно, если оно разрешено параметром.

Состояние хранится в памяти и ограничено числом отслеживаемых пользователей; вытеснение старой записи может сбросить ограничение для неё. Перезапуск также сбрасывает историю. [VKService](../../../../../src/services/vk/vkService.ts) создаёт экземпляр с `MAX_REQUESTS_PER_MINUTE` и окном 60 секунд. Сервис не проверяет роли и не гарантирует распределённое ограничение между процессами. Отдельного теста в текущем `test/` не обнаружено.

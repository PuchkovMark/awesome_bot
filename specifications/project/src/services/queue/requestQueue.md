# RequestQueue

**Тип:** сервис очередей. **Источник:** [requestQueue.ts](../../../../../src/services/queue/requestQueue.ts), класс `RequestQueue` и экземпляр по умолчанию. `add<T>(userId, fn)` возвращает результат или ошибку асинхронной функции; `getQueueForUser(userId)` возвращает `PQueue` с `concurrency: 1`.

Задачи с одинаковым строковым ключом исполняются последовательно, разные ключи имеют независимые очереди. После завершения всех ожидающих и выполняющихся задач очередь удаляется из карты, если она всё ещё является текущей для ключа. Состояние находится только в памяти, поэтому после перезапуска не восстанавливается; очередь не задаёт ограничения на суммарное число пользователей и не выполняет авторизацию. Используется в [VKService](../../../../../src/services/vk/vkService.ts) с идентификатором отправителя для сообщений без slash-префикса и авто-реакций. Сообщения с распознанным slash-префиксом запускают общий обработчик напрямую и не сериализуются ни с очередью, ни друг с другом; проверки прав, режима и ограничения частоты остаются в VK-маршруте. Отдельного теста в текущем `test/` не обнаружено.

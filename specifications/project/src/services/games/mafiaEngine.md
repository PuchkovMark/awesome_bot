# Движок мафии

**Тип:** чистые функции правил и разрешения ходов. **Источник:** [mafiaEngine.ts](../../../../../src/services/games/mafiaEngine.ts): `mafiaSettings`, `roleComposition`, `shuffleRoles`, `parseNightAction`, `tallyMafiaVotes`, `determineMafiaWinner`, `resolveNightActions` и типы состояний.

`mafiaSettings` ограничивает игроков 5–15, набор 30–600 секунд, ночь 15–300, обсуждение 15–600, голосование 10–300; defaults: 5 minimum, 15 maximum, target none, 120/60/90/45 секунд. Boolean defaults: revote on, reveal role on, dead talk off, spectate on. Ограничения чисел truncate до integer, а вне диапазона clamp-ятся. Явные `mafiaCount` clamp 1–7; специальные role toggles могут быть `null` для выбора по умолчанию.

`roleComposition` для сложности 1–4 включает роли при следующих минимальных размерах набора: Дон 10/10/8/7, Доктор 7/6/6/5, Комиссар 8/8/7/6, Маньяк 10/10/10/8 соответственно. Default число мафиози — `max(1,floor(players/4))`, максимум — `floor((players-1)/2)`. Дон включается автоматически только при пороге сложности и хотя бы двух мафиози. Если включённые мафия+спецроли оставляют менее одного мирного, состав отклоняется. Ошибки также возникают при размере партии вне 5–15 или некорректном числе мафиози. Перемешивание Fisher–Yates принимает внедряемый генератор индексов и отклоняет значение вне диапазона.

Парсер ночного действия зависит от роли и принимает целевой номер 1–15 с допустимыми русскими глаголами: комиссар `проверить|проверка|проверь`, Дон — те же для проверки и `убить|устранить|цель|мафия`/голый номер для убийства, мафия/маньяк — kill forms, доктор — `лечить|спасти|защитить|цель`/голый номер. Регистр и завершающая punctuation нормализуются.

`tallyMafiaVotes` считает только пары из переданных sets eligible voter/target; уникальный лидер устраняется, tie или ноль голосов возвращает `eliminatedId=null`. `resolveNightActions` принимает только живые actor/target: действия мафии/Дона суммируются, и атака происходит только при единственном лидере; маньяк наносит независимую атаку. Доктор отменяет все атаки на спасённую цель; self-heal учитывается, только если внешнее состояние `selfHealUsed` ещё false. Commissioner получает `мафия|не мафия`, Дон — `комиссар|не комиссар`; эти результаты направляются только соответствующему actor в сервисе. Победа города наступает при отсутствии мафии и маньяка; победа мафии — при равенстве/превышении численности остальных живых; маньяк побеждает, оставшись один. Модуль не хранит БД-состояние и не проверяет права.

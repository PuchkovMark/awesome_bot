# `gameEngine`

**Тип:** чистые определения видов игр, разбор настроек/действий и валидация ответов модели. **Источник:** [gameEngine.ts](../../../../../src/services/games/gameEngine.ts). Переходы сессий выполняет [GameService](gameService.md); специальные загадки — [riddleGeneration](riddleGeneration.md).

## Игры и настройки

| ID | Алиасы | Режим и краткое правило |
| --- | --- | --- |
| `quiz` | `quiz`, `викторина` | `answer`: первый правильный ответ получает очки. |
| `riddle` | `riddle`, `загадка`, `загадки` | `answer`: логические, математические и словесные загадки. |
| `character` | `character`, `персонаж`, `персонажа` | `answer`: угадывание вымышленного персонажа. |
| `word` | `word`, `слово`, `слова` | `answer`: слово по описанию, буквам, анаграмме или ассоциации. |
| `truth` | `truth`, `правда`, `действие` | `truth`: безопасное задание «правда или действие». |
| `who` | `who`, `вероятнее`, `кто вероятнее всего` | `vote`: голосование за участника. |
| `songfilm` | `songfilm`, `song`, `film`, `песня`, `фильм` | `answer`: угадывание произведения по непоэтической подсказке. |
| `association` | `association`, `ассоциация`, `ассоциации` | `association`: цепочка неповторяющихся смысловых ассоциаций. |
| `story` | `story`, `история` | `story`: участники продолжают общую историю. |
| `mafia` | `mafia`, `мафия`, `мафию` | `mafia`: отдельный [движок](mafiaService.md). |

Сложность 1–4 задаёт базовые `timeLimitSeconds/hintsPerRound/attemptsPerPlayer`: 90/3/3, 60/2/2, 45/1/2, 30/0/1. `settingsForDifficulty` ограничивает rounds 1–20 (default 5), `maxParticipants` 1–50 (default 20), время 10–300 секунд, подсказки 0–5, попытки 1–10; playMode принимает только `team`, иначе `individual`; `allowSkip` и `autoAdvance` по умолчанию `true`; категория NFKC очищается от управляющих символов, обрезается до 60 символов и при пустом значении становится `общее`. Переборные числовые overrides округляются и ограничиваются, non-finite/нечисловые значения заменяются default.

`difficultyFromValue` принимает integer 1–4 или префиксы `easy/medium/hard/expert` и русских названий; неизвестное значение даёт 2. `difficultyInText` ищет экспертный, сложный, средний, затем лёгкий маркеры и может вернуть `null`.

## Разбор запуска и действий

`parseGameStartOptions` сначала нормализует Unicode NFKC, lowercase и `ё→е`. Читает difficulty, rounds/вопросы, players/участников, time/время, hints/подсказок, attempts/попыток; категория извлекается только после `category|категория|тема` с `:` или `=` до запятой/точки с запятой. Упоминание команды/`team` включает командный режим, `индивидуал` устанавливает индивидуальный. `без пропуск` или `skip|пропуск=off|false|нет|выкл` отключает пропуски; `ручной переход` или `auto|авто=off|false|нет|выкл` отключает автоматическое продвижение. Прочие числовые значения не валидируются здесь: их ограничивает `settingsForDifficulty`.

`detectGameStartRequest(text, allowNaturalStart)` отказывается при выключенном флаге либо без слова намерения (`давай`, `хочу`, `можно`, `сыграем`, `сыграть`, `играем`, `начни`, `начнем/начнём`, `начинай`, `запусти`, `устроим`, `организуй`, `поиграем`, `угадай`, `загадай`). Затем ищет alias игры по границе пробела/пунктуации; русские алиасы допускают морфологические окончания от основы длиной не менее трёх букв. Извлекает сложность, число раундов/вопросов, тему после `про`/`на тему` и командный режим. В других случаях возвращает `null`.

`parseGameAction` обрабатывает команды с точным совпадением после нормализации и удаления завершающей пунктуации: pause/resume/stop/skip/hint/repeat/score/join, голос «за/против» за сложность, next round, pass, team/captain. Отдельно распознаёт повышение/понижение сложности при наличии текста о сложности/игре/уровне. Приоритет: изменение сложности до остальных шаблонов. Неизвестный текст возвращает `null`.

## Генерация и начисления

`parseGeneratedActivity` принимает только JSON object с `text` длиной 10–500. `parseGeneratedQuestion` требует JSON object, `text` 10–700, 1–4 непустых ответа длиной до 100, до 4 подсказок длиной до 180; `choices` отсутствует либо содержит 2–5 строк длиной до 120. Вопрос не должен совпадать с историей после нормализации и не должен включать правильный ответ длиной от трёх символов. Ответы нормализуются и дедуплицируются; варианты выбора не должны повторяться и ровно один должен совпасть с нормализованным правильным ответом. Допустимый `clueType`: `description`, `letters`, `scramble`, `emoji`; неизвестный тип игнорируется. JSON/контрактные ошибки бросают `Error`.

`pointsForCorrectAnswer` вычисляет base 1/2/3/5 по сложности, добавляет `floor(base × clamp(timeRemainingRatio,0,1))`, затем вычитает использованные hints и failed attempts с нижним пределом итогового значения 1. Отрицательные hint/attempt counts трактуются как ноль.

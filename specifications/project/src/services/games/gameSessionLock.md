# serializeGameConversation

**Тип:** внутрипроцессная блокировка игрового сценария. **Источник:** [gameSessionLock.ts](../../../../../src/services/games/gameSessionLock.ts), `serializeGameConversation<T>(conversationId, operation)`.

Операции с одинаковым conversation ID выполняются последовательно через цепочку Promise; разные беседы не блокируют друг друга. Результат или исключение `operation` возвращаются вызывающему, а lock освобождается в `finally` и удаляется, если за время выполнения не появился следующий элемент очереди. Карта локальна процессу, не восстанавливается после рестарта и не синхронизирует несколько экземпляров приложения. Отдельный тест lock не обнаружен.

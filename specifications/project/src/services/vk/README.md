# Интеграция VK

- [VkService](vkService.md) — запуск Long Poll, обработка callback/сообщений, маршрутизация в сервисы и AI.
- [vkFileDownload](vkFileDownload.md) — безопасная загрузка файлов с разрешённых хостов.
- [vkMention](vkMention.md) — разбор ссылок на пользователей и сопоставление имён.
- Общий порядок и поток сообщения также описаны в [архитектуре](../../architecture.md); контракт обработчика подробнее — в документе `VkService`.

# vkFileDownload

## Получение файлов VK

[vkFileDownload.ts](../../../../../src/services/vk/vkFileDownload.ts) для документов проверяет HTTPS, разрешённые хосты VK и их поддомены, отсутствие логина/пароля в URL и порт по умолчанию либо 443. Скачивание без редиректов, таймаут 20 секунд, предел размера задаётся вызывающим сервисом; пустой или превышающий предел файл отклоняется. Загрузка фото и аудио реализована отдельно в соответствующих сервисах, поэтому не следует предполагать идентичность всех проверок URL.

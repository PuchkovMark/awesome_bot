# VkUserReference и разбор ссылок на пользователя

**Тип:** функции разбора идентификатора VK. **Источник:** [vkMention.ts](../../../../../src/services/vk/vkMention.ts): `parseVkUserReference`, `matchesVkPersonName`.

`parseVkUserReference` принимает числовой ID, `@id123`, VK markup `[id123|имя]`, URL `vk.com/<screenName>` или screen name из латинских букв, цифр, `_` и `.`. Результат размечен как `id` или `screenName`; неподдерживаемый ввод возвращает `null`. `matchesVkPersonName` сравнивает ссылку без учёта регистра с именем/полным именем, а также допускает начало имени после удаления одной русской падежной/родовой конечной буквы, если корень не короче трёх символов. Авторизацию должен выполнять вызывающий сценарий. Отдельных тестов модуля не обнаружено.

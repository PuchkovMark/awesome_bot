# dateTime

**Тип сущности:** общий helper-модуль валидации аргументов AI tools. **Runtime identity:** экспортируемые `parseIsoDateTime` и `isRecord`. **Источник:** [`src/services/ai/tools/dateTime.ts`](../../../../../../src/services/ai/tools/dateTime.ts).

## Контракты

`parseIsoDateTime(value)` принимает только полную дату и время вида `YYYY-MM-DDTHH:mm:ss`, необязательную дробную часть от одной до трёх цифр и обязательную зону `Z` либо `±HH:mm`. Регулярное выражение требует секунды и верхний регистр `T`/`Z`; даты только с календарным числом, время без зоны, пробел вместо `T`, дробные доли длиннее трёх цифр и компактное смещение без двоеточия отвергаются. После проверки создаётся `Date`; функция возвращает её, если `getTime()` конечен, иначе `undefined`. Исключения и сообщения об ошибке не формируются.

Примеры допустимого формата: `2026-11-16T10:30:00Z`, `2026-11-16T10:30:00.5+03:00`. Примеры неподдерживаемой формы: `2026-11-16`, `2026-11-16T10:30Z`, `2026-11-16T10:30:00.1234Z`.

`isRecord(value)` возвращает type predicate только для ненулевых объектов, которые не являются массивами. Это runtime-проверка формы значения, а не валидация полей или JSON-схемы.

## Использование

`parseIsoDateTime` используется при разборе дат в [`localChatHistoryTool.ts`](../../../../../../src/services/ai/tools/localChatHistoryTool.ts), [`subagentTool.ts`](../../../../../../src/services/ai/tools/subagentTool.ts) и [`subagentTools.ts`](../../../../../../src/services/ai/tools/subagentTools.ts). Поэтому формулировка «ISO 8601 с часовым поясом» в публичных контрактах этих tools ограничена точной грамматикой выше. Она проверяет, что JavaScript создаёт конечный instant, но сама не задаёт независимую календарную проверку каждого компонента даты.

`isRecord` используется теми же модулями и [`subagentStatusTool.ts`](../../../../../../src/services/ai/tools/subagentStatusTool.ts) для проверки входных аргументов/ответов. Tool-specific сообщения и статусы валидации остаются в [едином каталоге инструментов](../tools.md).

## Границы и свидетельства

Модуль не обращается к БД, VK или внешним API, не меняет состояние и не логирует. Отдельного тестового файла для него нет; тестовые файлы инструментов-потребителей включают [`subagentTool.test.ts`](../../../../../../test/subagentTool.test.ts) и [`localChatHistoryTool.test.ts`](../../../../../../test/localChatHistoryTool.test.ts). Тесты в рамках проверки документации не запускались.

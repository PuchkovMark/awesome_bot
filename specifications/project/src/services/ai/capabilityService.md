# buildBotCapabilities

**Тип:** сборщик контекста возможностей. **Источник:** [capabilityService.ts](../../../../../src/services/ai/capabilityService.ts), `CapabilityContext`, `buildBotCapabilities`.

Функция формирует системный текст из текущего персонажа и доступных персонажей, провайдера, режима беседы, прав бота-администратора, разрешения на медиа, конфигурации ключей и поиска, а также настройки голоса пользователя. В тексте объясняются доступные инструменты, контекстные ограничения отправки сообщений и анализа вложений, память субагента и значения города/часового пояса по умолчанию. Для медиа возможность выводится по `isAdmin || imageAccess === 'all'`; поиск считается доступным при ненулевом провайдере и хотя бы одном ключе.

Это описание для модели, не серверная проверка полномочий. Реальные доступы повторно проверяются инструментами и обработчиками. Обновляя инструмент или условие его регистрации, нужно сверять этот текст с [матрицей инструментов](tools.md). Отдельных тестов модуля не обнаружено.

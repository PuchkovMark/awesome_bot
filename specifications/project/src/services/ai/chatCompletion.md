# sendChatCompletion

**Тип:** исполнитель OpenAI-совместимого chat completion и цикла инструментов. **Источник:** [chatCompletion.ts](../../../../../src/services/ai/chatCompletion.ts): `sendChatCompletion`, `AIOutputLimitError`.

Повторяющиеся имена инструментов запрещены. По умолчанию лимит — 10 вызовов на запрос; он считает вызовы по всем раундам. Каждый вызов должен иметь поддерживаемый тип, доступное имя и корректный JSON; результат `execute` добавляется как tool-сообщение. Неизвестные инструменты, неверные аргументы и превышение лимита завершаются ошибкой.

Каждый раунд передаёт модель, сообщения, лимит выходных токенов и reasoning effort; `options.signal`, если задан, передаётся SDK для отмены запроса; инструменты включаются с `tool_choice: auto`, если список не пуст. Usage суммируется. `finish_reason=length` вызывает `AIOutputLimitError`, content filter и пустой ответ — ошибки. Успешный результат содержит текст/refusal, провайдера, ID и счётчики токенов. Функция не доставляет ответ в VK; транспорт задаёт провайдер.

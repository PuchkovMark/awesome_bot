# historySnapshot

[`createHistorySnapshot` и `readHistorySnapshotPage`](../../../../../src/services/ai/historySnapshot.ts) обслуживают [прямой пересказ](directSubagentService.md). Первый выбирает ID `Message` конкретной беседы, роли user/assistant или заданных участников и период `[from, to)` по `sentAt`, а при его отсутствии по `createdAt`; сортирует по выбранному времени, `createdAt`, ID и при `count` оставляет последние записи. Это снимок состава, не текста: изменившийся текст читается заново, удалённый ID отмечается `missing`.

Второй читает выбранные ID в том же `conversationId`, восстанавливает исходный порядок и автора, время, ID сообщения и ответ. Для связанной цитаты поиск ограничен беседой, а подстановка содержимого связанной записи — ID снимка. Старые записи с распознанным `audio_message` в JSON `attachments` исключаются как текст; текст и цитаты очищаются через [cleanHistoryText](../memory/historyText.md). Сохранённый `replyToText` используется предпочтительно; происхождение старого текста или цитаты без надёжных метаданных восстановить нельзя. Это ограничение не меняет старые строки в БД. Прямых тестов модуля в `test/` нет.

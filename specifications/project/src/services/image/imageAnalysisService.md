# imageAnalysisService

[imageAnalysisService.ts](../../../../../src/services/image/imageAnalysisService.ts) анализирует фото либо документ с изображением. Для документа предел — 8 МиБ, сначала проверяется расширение; загрузка идёт через `downloadVkFile`. Изображение поворачивается, уменьшается максимум до 2048×2048 и передаётся как JPEG quality 85 в `OPENAI_MODEL`, лимит вывода 1200 токенов. Режим OCR использует отдельную инструкцию распознавания; системная инструкция считает текст на изображении недоверенным содержимым. Пустой ответ провайдера считается ошибкой.

Клиент создаётся при импорте только при `OPENAI_API_KEY`; timeout 90 секунд и `AI_MAX_RETRIES`. Фото VK скачивается через [ImageGenerationService.downloadPhoto](imageGenerationService.md); документ требует `isFilled` или загрузки payload, допустимое расширение `gif/jpeg/jpg/png/webp`, URL и размер не больше 8 МиБ, затем скачивается с проверкой разрешённого HTTPS host и без редиректов. Формат содержимого изображения проверяет Sharp при декодировании; GIF также преобразуется в JPEG-кадр/изображение.

Запрос отправляется в OpenAI Chat Completions с `detail=high`; системная инструкция запрещает исполнять текст, нарисованный на изображении, и делать выводы о личности/диагнозе по внешности. OCR меняет пользовательскую инструкцию на точное извлечение читаемого текста. Пустой ответ — ошибка. Вложения и пользовательский prompt покидают приложение и передаются провайдеру; права и привязку вложения устанавливает вызывающий инструмент/маршрутизатор. Прямого модульного теста ImageAnalysisService не найдено.

# Безопасная проекция ошибки изображения

**Тип:** функция фильтрации полей ошибки. **Источник:** [imageError.ts](../../../../../src/services/image/imageError.ts), `getSafeImageErrorDetails`.

Для объекта `Error` возвращает имя и сообщение, а также числовой status, строковый/числовой code и строковый param, если свойства присутствуют. Для другого значения возвращает `UnknownError` и `String(error)`. Функция не маскирует произвольные секреты, которые могли попасть в само сообщение; перед логированием внешних ошибок вызывающий код должен использовать её и учитывать содержимое `message`.

`ImageNotExecutedError` сохраняет исходную причину в `cause` и её сообщение.
`isImageNotExecutedError` проверяет этот класс. Генератор оборачивает только ошибки
подготовки до Images API: отсутствие клиента, downloadPhoto, Sharp и toFile.
API-вызов и разбор ответа не входят в этот catch. Это основание возврата
[квоты](imageQuotaService.md), а не классификация по HTTP-коду или тексту ошибки.

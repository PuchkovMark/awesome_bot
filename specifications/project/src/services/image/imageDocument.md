# Проверка расширения изображения-документа

**Тип:** функция проверки типа файла. **Источник:** [imageDocument.ts](../../../../../src/services/image/imageDocument.ts), `isImageDocumentExtension`.

Возвращает `true` только для расширений `gif`, `jpeg`, `jpg`, `png`, `webp` без учёта регистра (`en-US`); отсутствующее или иное расширение отклоняется. Это проверка расширения документа VK и не является полной проверкой MIME, сигнатуры или безопасности содержимого. Вызывающий анализатор должен дополнительно применять ограничения загрузки и размера.

## Фоновые задания

В `src/jobs/` находятся задания очистки, игровых таймеров и голосований, мемов, напоминаний, долговременной памяти и доставки результатов субагентов. `scheduler.ts` управляет зарегистрированными задачами. Часть заданий запускается при старте VK, остальные — в `bootstrap.ts`; при изменении запуска или остановки учитывайте повторную регистрацию и восстановление после перезапуска.

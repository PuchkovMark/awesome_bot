# historyText

[`cleanHistoryText`](../../../../../src/services/memory/historyText.ts) удаляет emoji, включая keycap, пары региональных индикаторов и последовательности pictographic с модификаторами, затем применяет `trim`. Используется при [сохранении Message](memoryService.md) и чтении старых записей для [прямого снимка](../ai/historySnapshot.md). Это обработка текста, не проверка происхождения аудио или вложений; старые строки не переписываются. Прямых тестов модуля в `test/` нет.

# SplitterService

**Тип:** сервис форматирования. **Источник:** [splitterService.ts](../../../../../src/services/splitter/splitterService.ts), `SplitterService` и экземпляр по умолчанию; `MAX_VK_MESSAGE_LENGTH = 4000`. Конструктор принимает положительную целую максимальную длину, иначе выбрасывает ошибку.

`split(text)` возвращает последовательные части длиной не больше лимита; пустая строка даёт пустой массив. В пределах последних 40% допустимой длины предпочтение отдаётся переводу строки, затем пробелу, иначе выполняется жёсткий разрез. Граница не разделяет суррогатную пару Unicode; слишком маленький лимит может вызвать ошибку. Длина определяется в единицах JavaScript, а не графемах.

`truncate(text, notice, suffix = '')` резервирует место для суффикса, при необходимости обрезает текст и добавляет уведомление и суффикс. Ошибка возникает, если суффикс длиннее лимита или уведомление не помещается при необходимом сокращении. Сервис используется `SenderService` и `VoiceResponseService`, не выполняет сетевых запросов и не проверяет права. Специального теста в текущем `test/` не обнаружено.

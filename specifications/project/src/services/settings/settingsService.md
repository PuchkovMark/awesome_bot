# SettingsService

**Тип:** сервис настроек и ролей. **Источник:** [settingsService.ts](../../../../../src/services/settings/settingsService.ts), `SettingsService` и singleton.

Получение пользовательских и беседовых настроек выполняет `upsert`, создавая `User`/`Conversation` и соответствующую запись настроек. Для новой беседы `isGroup` определяется сравнением conversation ID с 2 млрд. Начальные настройки беседы включают режим и доступ к изображениям из конфигурации, приветствие и JSON со списком вопросов анкеты.

Методы сохраняют часовой пояс после проверки через `Intl.DateTimeFormat`; системные инструкции ограничены 2000 символами после trim, пустое значение очищает поле. Местоположение хранится в полях имени, координат, страны, региона и часового пояса. Очистка часового пояса сбрасывает также `locationTimeZone`. Настройки анкеты вопросов сериализуются JSON. Методы режимов/прав принимают типизированные значения, но самостоятельной проверки вызывающей роли не делают.

Создатель определяется фиксированным `BOT_CREATOR.vkId`; администраторы — конфигурацией `VK_ADMIN_IDS` либо таблицей `Admin`. Создателя нельзя добавить/удалить как обычного администратора; конфигурационных администраторов удалить из БД также нельзя. AppSetting — произвольная пара key/value; журнал действий создаёт `AdminLog`. Персистентность — Prisma/SQLite. Проверки прав должны выполняться command/router до вызова методов изменения.

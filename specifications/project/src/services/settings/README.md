# Настройки

- [SettingsService](settingsService.md) — пользовательские/беседовые настройки и роли.
- [CharacterService](characterService.md) — каталог персонажей, доступность, выбор и версии.
- [personalityService](personalityService.md) — встроенные профили, legacy-ID, валидация настроек и генерация style prompt.
- [LocationService](locationService.md) — город и часовой пояс.
- [locationDefaults](locationDefaults.md) — значения по умолчанию.

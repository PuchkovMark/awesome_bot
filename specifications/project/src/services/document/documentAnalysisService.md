# documentAnalysisService

## Документы

[documentAnalysisService.ts](../../../../../src/services/document/documentAnalysisService.ts) поддерживает расширения `pdf`, `docx`, `odt`, `pptx`, `xlsx`, `csv`, `json`, `md`, `rtf`, `txt`. Заявленный и скачанный размер ограничен 8 МиБ. Перед отправкой проверяется сигнатура `%PDF-` для PDF, первые байты ZIP для архивных форматов и отсутствие нулевого байта для текстовых; эти проверки не являются полным разбором содержимого.

Файл целиком передаётся в OpenAI Responses API как `input_file` с соответствующим MIME и инструкцией пользователя; для PDF задан `detail=high`, модель — `OPENAI_MODEL`, лимит вывода 1200 токенов. Инструкция требует рассматривать содержимое документа как данные, а не как управляющие команды. Отсутствие ключа, URL, поддерживаемого расширения или непустого ответа приводит к ошибке сервиса.

**Контракт:** `isSupportedDocumentExtension` сравнивает расширение без учёта регистра с каталогом `pdf`, `docx`, `odt`, `pptx`, `xlsx`, `csv`, `json`, `md`, `rtf`, `txt`; MIME выбирается по расширению, заголовок VK не является источником типа. `analyze(document,prompt)` при незагруженном payload вызывает `loadAttachmentPayload`, затем проверяет расширение, URL и заявленный размер, скачивает через [downloadVkFile](../vk/vkFileDownload.md) и проверяет фактический размер/минимальную сигнатуру. ZIP-проверка проверяет только `PK`; для текстовых запрещён NUL, но полная проверка формата не выполняется.

Клиент создаётся при импорте сервиса только при наличии `OPENAI_API_KEY`, `maxRetries=AI_MAX_RETRIES`, timeout 90 секунд. Пустой prompt заменяется просьбой кратко изложить документ; пустой результат Responses API — ошибка. Содержимое документа и prompt отправляются OpenAI, файл целиком кодируется в data URL. Вызовы есть в прямых document-командах и `analyze_attachment`; доступы и выбор документа принадлежат этим вызывающим путям. Тесты сервиса напрямую не обнаружены.
